# Сторонние компоненты и лицензии

Таблица собрана по файлам репозитория. Столбец «Проверено» означает:

- **да** — лицензия подтверждена текстом из репозитория или публичным источником;
- **нет** — лицензия не подтверждена, нужна проверка перед публикацией.

Этот документ не юридическая экспертиза. Решения по рискам принимает
владелец проекта с юристом (см. `docs/legal/LEGAL_REVIEW.md`).

## Что нужно сделать до публикации

1. Готово: шрифты перегенерированы из Inter (OFL 1.1), Segoe UI удалён.
2. Установить лицензию `autopid_for_esp_idf` или заменить компонент.
3. Решить вопрос с esptool (GPL-2.0) в `Automatika.exe`.
4. Подтвердить лицензии, помеченные «нет», по исходным репозиториям.
5. Добавить `NOTICE`-файл с текстами лицензий в exe, APK и архив прошивки.
