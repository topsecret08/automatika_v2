# Матрица совместимости контроллер ↔ HMI

Источник версий — [`VERSION.json`](../VERSION.json).

| Контроллер | HMI-панель | Протокол | Статус |
|---|---|---|---|
| `V1.0.1` (`v1.0.1-ctrl1`) | `0.9.6-hmi1` (`v0.9.6-hmi1`) | `1.0.0` | Первая связка, план проверки 2026-12-06 |

## Правила

- Протокол `1.0.0` считается совместимым внутри мажорной версии `1.x`.
- HMI — master шины. Контроллер отвечает только на `POLL`, `CMD`,
  `GET_CONFIG`, `PING`.
- При несовпадении мажорной версии протокола HMI показывает «НЕТ СВЯЗИ»
  и не отправляет `CMD`.
- Интерфейс `can_hmi` на контроллере можно выключить через
  `CONFIG_HMI_CAN_ENABLE=n`: остальная прошивка продолжает работать.

## Пределы

- `115200 8N1`, `POLL 500 мс`, timeout `100 мс`, 2 повтора.
- Поток ~`504 B/с` ≈ `4.4 %` линии; на `57600` ≈ `8.8 %`.
- Потеря 3 ответов = 1.5 с → «НЕТ СВЯЗИ». Последние safety-биты остаются
  на экране, но HMI не принимает решений по безопасности.
