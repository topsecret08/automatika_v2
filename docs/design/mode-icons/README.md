# Иконки режимов\n\nПростые контурные пиктограммы для шести режимов из референса: rectify (ректификация), distill (дистилляция), beer (пивоварение), pvk (ПВК), nbk (НБК), vacuum (вакуумная перегонка). Цвет штрихов #c8d6e8, сетка 96x96.\n\nВ APK подключены: подменю «Старт» показывает пиктограмму для режимов дистилляция, ректификация, пивоварение, ПВК, НБК и вакуумная перегонка. Векторные версии лежат в `android/app/src/main/res/drawable/ic_mode_*.xml` и должны совпадать с SVG здесь. Двойная перегонка и брожение пока с эмодзи. PWA не подключён.\n
