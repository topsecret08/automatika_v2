# Быстрый старт (15 минут)

От распаковки до первого запуска. Подробности — в
[USER_GUIDE.md](USER_GUIDE.md); установка PWA — в
[PWA_INSTALL.md](PWA_INSTALL.md).

## 1. Что понадобится

- Собранное устройство Automatika v2 с прошивкой v2.9.3.
- Телефон или ноутбук с Wi-Fi 2.4 ГГц.
- Розетка 220 В с заземлением и УЗО.
- Вода для охлаждения и жидкость для перегонки (не менее 15 % объёма куба).

## 2. Подключение

1. Подключите охлаждение (вход/выход воды).
2. Залейте жидкость в куб — не ниже минимального уровня.
3. Закройте крышку, проверьте, что E-STOP **не нажат**.
4. Включите питание. Экран должен показать заставку и главный экран.

> Не включайте нагрев без заполненного куба и поданного охлаждения.

## 3. Подключение к Wi-Fi

При первом запуске (или после сброса настроек) устройство поднимает открытую
точку доступа **`Automatika-Setup`**.

1. На телефоне откройте Wi-Fi и подключитесь к `Automatika-Setup`.
2. Запустите приложение **ESP SoftAP Prov** (Espressif, Android/iOS) либо
   `esp_prov.py` из ESP-IDF.
3. Устройство: `Automatika-Setup`, транспорт `softap`.
4. Введите SSID и пароль вашей сети **2.4 ГГц**.
5. Дождитесь сообщения об успехе. Устройство перезагрузит Wi-Fi и
   подключится к вашей сети.

Пароля у точки доступа нет (provisioning с безопасностью 0). Не оставляйте
устройство в режиме настройки в людном месте дольше необходимого.

## 4. Открыть веб-интерфейс

1. В браузере откройте `http://automatika.local`
   (если mDNS не работает — IP-адрес устройства из списка клиентов роутера).
2. Перейдите в **Система → API-ключ**.
3. Нажмите **«Сгенерировать»**. Ключ создастся и сохранится
   в этом браузере. Это одноразовая операция: пока ключ не создан, устройство
   разрешает его bootstrap; дальше — только с текущим ключом.
4. Вернитесь в **Работа → Дашборд** — статус должен стать `Online`.

> Ключа по умолчанию в прошивке нет. Если кто-то успел создать ключ раньше
> вас, выполните сброс настроек (см. SERVICE_MANUAL.md) и повторите.

## 5. Установить PWA (по желанию)

1. Откройте `https://automatika.local`.
2. Примите предупреждение самоподписанного сертификата (или установите
   `cert.pem` как доверенный — [PWA_INSTALL.md](PWA_INSTALL.md)).
3. Chrome (Android): кнопка **«Установить»** в шапке или меню →
   «Установить приложение».
4. Safari (iOS): «Поделиться» → «На экран "Домой"».

После установки приложение открывается без адресной строки, работает
офлайн-оболочка и ярлыки «Дашборд», «Журнал», «Настройки».

## 6. Первый запуск процесса

1. Проверьте показания: куб и царга должны быть близки к комнатной
   температуре, проток охлаждения — больше 0.5 л/мин.
2. Установите мощность вручную (например, 30–40 %) и убедитесь, что
   температура растёт.
3. Для автоматического режима настройте профиль и PID (см.
   [USER_GUIDE.md](USER_GUIDE.md), раздел «Профили и PID»).
4. Запуск: кнопка **«Старт»**. Остановка: **«Стоп»**.
5. Следите за журналом: вкладка **«Журнал»** (нужен API-ключ).

## 7. Если что-то пошло не так

- Не греет — [TROUBLESHOOTING.md](../service/TROUBLESHOOTING.md), §2.1.
- Нет Wi-Fi — §2.5.
- PWA не устанавливается — §2.6 и [PWA_INSTALL.md](PWA_INSTALL.md).
- Авария/E-STOP — немедленно отключите питание, затем см.
  [SERVICE_MANUAL.md](../service/SERVICE_MANUAL.md).
