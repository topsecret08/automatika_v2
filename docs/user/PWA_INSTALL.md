# Установка PWA на телефон

Веб-интерфейс Automatika можно установить как приложение. Оно открывается
без адресной строки, кэширует оболочку и работает как обычное приложение
(иконка на домашнем экране, свои ярлыки).

## 1. Что нужно

- Устройство Automatika в той же сети Wi-Fi (2.4 ГГц).
- Имя `automatika.local` резолвится через mDNS, либо IP-адрес устройства.
- Включённый HTTPS-сервер (в прошивке v2.9.3 включён по умолчанию,
  `WEB_HTTPS_ENABLE=1`, порт 443).
- Телефон с Chrome (Android) или Safari (iOS).

## 2. Почему HTTPS обязателен

Браузеры разрешают Service Worker и установку PWA только в secure context:
`https://` или `http://localhost`. По `http://<IP>` интерфейс откроется, но
кнопки «Установить» не будет, а офлайн-режим не заработает.

Прошивка генерирует самоподписанный сертификат EC P-256 при первом старте:

- `/lfs/cert.pem` — публичная часть, её можно скачать:
  `http://automatika.local/cert.pem`;
- `/lfs/key.pem` — приватный ключ, наружу **не отдаётся** (статический
  обработчик блокирует `.pem`).

Сертификат выпущен для `CN=automatika.local` с SAN `DNS:automatika.local`.
По IP он будет считаться чужим — открывайте именно по имени.

## 3. Быстрый путь (без установки сертификата)

1. Откройте `https://automatika.local`.
2. Браузер покажет предупреждение «Подключение не защищено».
3. Chrome (Android): «Дополнительно» → «Перейти на сайт».
   Safari (iOS): «Подробнее» → «Посетить сайт».
4. Интерфейс откроется. В Chrome появится кнопка «Установить» в шапке.
5. Нажмите её (или меню ⋮ → «Установить приложение»).

Это работает, но предупреждение будет появляться при каждом новом запуске
браузера, а некоторые функции (например, push) могут быть ограничены.
Для постоянного использования установите сертификат как доверенный.

## 4. Установка сертификата

### 4.1. Скачать сертификат

На телефоне откройте `http://automatika.local/cert.pem` — файл
`automatika-cert.pem` скачается. Альтернатива: `curl -O
http://automatika.local/cert.pem` с компьютера и передать файл на телефон.

### 4.2. Android

Путь меню зависит от прошивки; ориентиры:

1. «Настройки» → «Безопасность» → «Шифрование и учётные данные».
2. «Установить сертификат» → «Сертификат CA».
3. Предупреждение «Ваши данные не будут зашифрованы» → «Всё равно
   установить».
4. Выберите скачанный `automatika-cert.pem`.
5. Сертификат появится в списке пользовательских CA.

Android 11+ может не показывать файл в диалоге — откройте его через
«Файлы» → «Установить сертификат» либо через настройки безопасности.

### 4.3. iOS / iPadOS

1. Передайте `automatika-cert.pem` на телефон (AirDrop, почта, «Файлы»).
2. Откройте файл → «Разрешить» установку профиля.
3. «Настройки» → «Основные» → «VPN и управление устройством» →
   «Загруженный профиль» → «Установить» → введите код-пароль.
4. «Настройки» → «Основные» → «Об этом устройстве» →
   «Доверие сертификатам» → включите полное доверие для `automatika.local`.

Без шага 4 сертификат установлен, но не доверен.

### 4.4. Проверка

Откройте `https://automatika.local` — замок в адресной строке должен быть
без предупреждения. Если предупреждение осталось, проверьте, что открываете
по имени, а не по IP, и что сертификат действительно в списке доверенных.

## 5. Установка приложения

### Android / Chrome

- Кнопка **«Установить»** в шапке интерфейса (появляется, когда браузер
  считает приложение устанавливаемым), либо
- меню ⋮ → **«Установить приложение»** / «Добавить на главный экран».

### iOS / Safari

1. Кнопка «Поделиться» (квадрат со стрелкой).
2. «На экран "Домой"».
3. «Добавить».

Safari не показывает кнопку установки автоматически — это нормально.

### Desktop (Chrome/Edge)

Иконка установки в адресной строке справа, либо меню → «Установить
Automatika».

## 6. Что появляется после установки

- Иконка **Automatika** на домашнем экране.
- Запуск в standalone-режиме (без адресной строки браузера).
- Ярлыки долгого нажатия: **Дашборд**, **Журнал**, **Настройки**
  (из `manifest.json`).
- Кэш оболочки `automatika-v293-ios-4`: HTML, CSS, JS, иконки, offline-страница.
- При отсутствии связи открывается страница «Нет связи» с кнопкой
  «Повторить». API и WebSocket никогда не кэшируются — данные всегда живые.

## 7. Обновление интерфейса

При обновлении прошивки меняйте `CACHE_NAME` в `littlefs/sw.js`
(сейчас `automatika-v293-ios-4`). Старый кэш удаляется при активации нового
Service Worker. Если интерфейс «залип» на старой версии:

1. Закройте приложение.
2. Chrome: «Настройки сайтов» → Automatika → «Очистить данные».
3. Откройте заново.

## 8. Если не устанавливается

| Симптом | Причина | Решение |
|---|---|---|
| Нет кнопки «Установить» | открыто по HTTP/IP | откройте `https://automatika.local` |
| «Не удалось установить» | сертификат не принят | примите сертификат или установите как доверенный |
| Белый экран | старый кэш | очистите данные сайта |
| Нет иконки | manifest не загрузился | проверьте `GET /manifest.json` |
| Service Worker `failed` | mixed content / HTTP | только HTTPS, без HTTP-ресурсов |
| iOS не предлагает установку | это Safari-ограничение | вручную «На экран "Домой"» |

Диагностика в Chrome: DevTools → Application → Manifest / Service Workers /
Cache Storage. На телефоне удобнее через `chrome://inspect` с компьютера.
