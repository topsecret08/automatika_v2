# Пошаговая инструкция: прошить, настроить, пользоваться

Инструкция для первого запуска Automatika V0.9 beta. Если вы никогда не
работали с ESP32 и ESP-IDF — идите по шагам сверху вниз, ничего не пропуская.

> **Сначала безопасность.** Автоматика не заменяет УЗО, заземление,
> предохранители, термостат и механический E-STOP. Первый запуск делайте без
> спирта, с водой, под присмотром и с исправной кнопкой аварийного останова.

## 1. Что понадобится

**Железо:**

- плата ESP32-S3 с 16 МБ flash и PSRAM;
- внешняя HMI-панель по RS485 или веб-интерфейс — рекомендуется;
- USB-кабель с передачей данных;
- блок питания платы;
- для реального процесса: ТЭН, SSR или внешний регулятор, датчики DS18B20,
  охлаждение, клапаны, E-STOP.

**Компьютер:**

- Windows 10/11, Linux или macOS;
- свободный USB-порт;
- интернет для первой сборки (скачиваются компоненты ESP-IDF).

**Минимум для старта без процесса:** плата, USB, Wi-Fi и браузер. Прошивка
загрузится, но нагрев будет заблокирован, пока не настроен регулятор.

## 2. Установите ESP-IDF

Нужен **ESP-IDF 5.3.x**. Версия 5.3.2 — проверенная.

### Windows

1. Установите Espressif Installation Manager:
   ```powershell
   winget install Espressif.EIM-CLI
   ```
2. Установите IDF:
   ```powershell
   eim install -p C:\Espressif -i v5.3.2 -t esp32s3 -a true
   ```
3. Активируйте окружение в PowerShell:
   ```powershell
   C:\Espressif\v5.3.2\esp-idf\export.ps1
   ```
   Если PowerShell блокирует скрипт:
   ```powershell
   Set-ExecutionPolicy -Scope Process Bypass
   ```

### Linux / macOS

```bash
git clone -b v5.3.2 --recursive https://github.com/espressif/esp-idf.git
cd esp-idf
./install.sh esp32s3
. ./export.sh
```

Проверка:

```bash
idf.py --version
```

Должно быть `ESP-IDF v5.3.x`.

## 3. Скачайте проект и соберите

```bash
cd automatika_v2
idf.py set-target esp32s3
idf.py build
```

На Windows перед сборкой включите UTF-8, иначе `idf.py` может споткнуться о
кириллицу в `sdkconfig`:

```powershell
$env:PYTHONUTF8=1
```

Или используйте готовый скрипт:

```powershell
.\tools\bootstrap.ps1 all
```

Linux/macOS:

```bash
./tools/bootstrap.sh all
```

Успешная сборка заканчивается словами `Project build complete`.

## 4. Первая прошивка по USB

1. Подключите плату USB-кабелем.
2. Узнайте порт:
   - Windows: Диспетчер устройств → Порты (COM и LPT), например `COM5`;
   - Linux: `/dev/ttyUSB0` или `/dev/ttyACM0`;
   - macOS: `/dev/cu.usbserial-*`.
3. Прошейте:
   ```bash
   idf.py -p COM5 flash monitor
   ```
   На Linux/macOS подставьте свой порт.

`monitor` показывает журнал. Выход — `Ctrl+]`.

Если порт не находится:

- проверьте, что кабель передаёт данные, а не только питание;
- установите драйвер CP210x или CH340;
- нажмите и удерживайте `BOOT`, коротко нажмите `RESET`, отпустите `BOOT`,
  повторите прошивку.

## 5. Первый запуск

После прошивки плата перезагрузится.

1. Экран должен показать заставку и главный экран.
2. Если экрана нет — откройте монитор порта и проверьте, что плата стартует
   без ошибок питания.
3. Не включайте нагрев. Сначала Wi-Fi и настройки.

## 6. Подключите Wi-Fi

При первом запуске устройство поднимает точку доступа **`Automatika-Setup`**.

1. На телефоне откройте Wi-Fi и подключитесь к `Automatika-Setup`.
2. Запустите приложение **ESP SoftAP Prov** (Espressif) или `esp_prov.py`.
3. Транспорт — `softap`.
4. PoP-код по умолчанию: **`automatika-setup`**.
5. Введите SSID и пароль домашней сети **2,4 ГГц**.
6. Дождитесь сообщения об успехе.

> Точка доступа защищена PoP-кодом, но код по умолчанию есть в исходниках.
> Перед постоянной эксплуатацией смените `PROV_POP_TEXT` в `main/config.h` и
> пересоберите прошивку.

Если Wi-Fi не подключился, устройство снова поднимет точку доступа. Проверьте,
что сеть 2,4 ГГц и пароль верный.

## 7. Откройте веб-интерфейс и создайте ключ

1. В браузере откройте `http://automatika.local`.
   Если mDNS не работает — IP-адрес устройства из списка клиентов роутера.
2. Перейдите **Система → API-ключ**.
3. Нажмите **Сгенерировать**.
4. Сохраните ключ. Он хранится в этом браузере; на другом устройстве его нужно
   ввести заново.

Пока ключа нет, устройство разрешает только первичное создание. Если ключ
потерян, потребуется сброс настроек.

По желанию установите PWA:

- Chrome (Android): кнопка **Установить**;
- Safari (iPhone): **Поделиться → На экран «Домой»**.

## 8. Заполните карту оборудования

Это самый важный шаг. Прошивка не должна управлять тем, чего у вас нет.

1. Откройте **Подготовка → Оборудование**.
2. Укажите роли DS18B20:
   - куб;
   - колонна;
   - рубашка;
   - бак.
   Индекс — порядок датчика на шине. Если не знаете, посмотрите показания на
   экране устройства или в разделе проверки датчиков.
3. Отметьте только реально подключённые устройства:
   давление, вакуум, уровень, весы, флегмовый клапан, насос
   охлаждения, клапан воды, вакуумный насос, мешалка, дозатор, клапаны.
4. Нажмите **Сохранить**.
5. Посмотрите блок «Готовность режимов»: напротив нужного режима должно быть
   «готов».

Минимальный набор:

| Режим | Обязательно |
|---|---|
| Дистилляция | датчик куба |
| Ректификация | куб + колонна + reflux или клапаны |
| Пивоварение | датчик куба |
| НБК | куб + колонна + дозатор |
| ПВК | датчик рубашки |
| Вакуум | куб + датчик вакуума + вакуумный насос |
| Двойная | датчик куба |
| Брожение | куб или бак |

Если минимального набора нет, запуск будет отклонён с причиной в журнале.

## 9. Настройте регулятор нагрева

Без этого нагрев заблокирован.

1. Откройте **Подготовка → Калибровка**.
2. Выберите регулятор:
   - **SSR PWM** — обычный SSR/МОСФЕТ;
   - **Finglai SSVR** — внешний преобразователь PWM→аналог;
   - KVIC / РМВ-К / SEM — внешний UART-регулятор.
3. Укажите свободный GPIO. Для ESP32-S3 подходят 7, 40, 41, 42, 47, 48.
   Не используйте 22–25: их физически нет.
4. Для SSR задайте частоту и разрядность, например 1000 Гц и 10 бит.
5. Сохраните.
6. Убедитесь, что в состоянии `regulator_ready = 1` и нет ошибки регулятора.

Пока GPIO равен `-1`, нагрев запрещён — это защита, а не поломка.

## 10. Калибровки

Делайте до первого процесса.

- **DS18B20:** экран устройства → **Датчики → Калибровка DS18B20**.
  Проверьте в ледяной воде и при кипении.
- **Весы HX711:** экран → **Весы HX711 → Тарировать**, затем **Калибровка** с
  известным весом.
- **Дозатор:** задайте `steps_per_ml` в **Калибровка** или на экране. Проверьте
  на 10 мл.
- **Клапаны:** экран → **Клапаны → Калибровка**, если используете ШИМ-клапаны.
- **I2C-степпер:** включается через `/api/stepper`; калибровка описана в
  `docs/hardware/I2C_STEPPER.md`.

## 11. Выберите режим и запустите

### Из веб-интерфейса

1. Откройте **Работа → Дашборд**.
2. В поле **Режим** выберите процесс.
3. Нажмите **Старт**.
4. Если запуск отклонён — проверьте E-STOP, карту оборудования и журнал.

### С экрана устройства

**Меню → Режимы работы → нужный режим → Старт.** Если включены роли, может
потребоваться PIN оператора/инженера.

## 12. Первая ректификация по шагам

1. Залейте в куб жидкость не ниже минимального уровня и не выше максимума.
2. Подключите охлаждение, откройте воду.
3. Убедитесь, что E-STOP **не нажат**.
4. Включите питание.
5. В **Оборудовании** проверьте куб, колонну, клапаны и reflux.
6. Установите уставки: температура куба/колонны, объём голов, скорость тела,
   флегмовое число.
7. Запустите режим **Ректификация**.
8. Дождитесь этапа **Стабилизация**: температура колонны должна выйти на полку.
9. Этап **Головы**: малый отбор, следите за графиком и ΔT.
10. Этап **Тело**: основной отбор; при росте температуры колонны скорость
    автоматически снижается.
11. Этап **Хвосты**: отбор в отдельную ёмкость.
12. **Стоп**, дождитесь охлаждения, слейте куб.

Во время процесса:

- график на дашборде показывает куб и пар;
- нажмите на график — откроется журнал с аномалиями;
- параметры с карандашом можно менять на ходу;
- при аварии сначала устраните причину, затем **Сброс аварии**.

## 13. Остальные режимы коротко

- **Дистилляция:** куб, нагрев, отбор по температуре/объёму.
- **Пивоварение:** рецепт по шагам; насос, мешалка и весы — если включены.
- **НБК:** сначала стабилизация колонны, затем плавная подача браги.
- **ПВК:** регулятор рубашки, вода/пар, контроль давления и уровня.
- **Вакуум:** вакуумный насос держит давление по температуре кипения.
- **Брожение:** температура бака/куба, нагрев или охлаждение.
- **Двойная перегонка:** два прохода с поправкой на давление.

Не включайте НБК, ПВК и вакуум без соответствующих датчиков и аппаратных защит.

## 14. График, журнал и параметры

- График компактный, история — до 2 часов в браузере.
- Нажмите на график: журнал температур, красные строки — аномалии, оранжевые —
  предупреждения.
- «Обновить» подтягивает события, «Очистить» удаляет локальную историю.
- Параметры с иконкой карандаша кликабельны: откроется окно с диапазоном,
  шагом и кнопками «−/+».
- Замок означает, что параметр нельзя менять во время процесса.

## 15. Обновление прошивки по Wi-Fi

1. Остановите процесс.
2. Откройте **Система → Обновление**.
3. Выберите `.bin` или HTTPS-ссылку.
4. Дождитесь перезагрузки. Не выключайте питание.
5. Если новая прошивка не подтвердится за 30 секунд, сработает откат.

Ограничения: образ не больше 3 МБ, процесс должен быть остановлен. Альтернатива —
конфигуратор:

```bash
python -m tools.configurator
```

## 16. Резервная копия

Перед экспериментами сохраните конфигурацию:

```bash
curl -X POST -H "X-API-Key: ВАШ_КЛЮЧ" \
  -H "Content-Type: application/json" \
  -d '{"path":"/sdcard/cfg.json"}' \
  http://automatika.local/api/config/export
```

Файл появится на SD. Импорт — через `/api/config/import` или экран устройства.

## 17. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| `idf.py` не найден | Активируйте `export.ps1` / `export.sh` |
| Порт не найден | Драйвер CP210x/CH340, кабель, кнопка BOOT |
| Нет точки `Automatika-Setup` | Питание, сброс настроек, монитор порта |
| `401 Unauthorized` | Введите API-ключ в PWA |
| Запуск отклонён | E-STOP, карта оборудования, журнал |
| Нет нагрева | Регулятор не настроен, GPIO `-1`, процесс не запущен |
| Температура `-127 °C` | Датчик не подключён или выбран неверный индекс |
| Постоянно «уровень низкий» | Датчик уровня включён в карте, но не подключён |
| Авария TSA | Нет охлаждения/потока воды, перегрев ТСА |
| График пуст | Нет связи, API-ключ, процесс не запущен |
| OTA отклонён | Процесс запущен или образ больше 3 МБ |
| PWA показывает старое | Обновите страницу, очистите кэш |

## 18. Ежедневный чек-лист

- [ ] E-STOP исправен и не нажат.
- [ ] Куб заполнен, уровень в норме.
- [ ] Охлаждение подключено, вода идёт.
- [ ] Карта оборудования соответствует реально подключённым датчикам.
- [ ] Регулятор готов, GPIO задан.
- [ ] Уставки и объёмы проверены.
- [ ] Журнал и график открываются.
- [ ] Известно, где кнопка «Стоп» и «Сброс аварии».
