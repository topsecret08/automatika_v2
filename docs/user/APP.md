# Automatika для Windows — установка и инструкция

Приложение **Automatika** для Windows находит плату по USB, прошивает её и
обновляет до последней версии. Вводить адреса и ключи вручную не нужно.

## 1. Скачать

1. Откройте страницу релизов: https://github.com/topsecret08/automatika_v2/releases
2. В последнем релизе скачайте два файла:
   - `Automatika-<версия>.exe` — само приложение;
   - `SHA256SUMS-app.txt` — контрольная сумма (по желанию, см. раздел 6).
3. Положите `.exe` в любую папку, например `Документы\Automatika`.

Установка не нужна: приложение запускается двойным щелчком.

## 2. Первый запуск

Windows может показать предупреждение «Windows защитила ваш компьютер»
(SmartScreen), потому что приложение не подписано коммерческим сертификатом.

1. Нажмите **Подробнее**.
2. Нажмите **Выполнить в любом случае**.

## 3. Драйвер платы

Большинство плат ESP32-S3 имеют USB-мост CH343/CH340 или CP2102. Windows
обычно ставит драйвер сама. Если в диспетчере устройств плата с
восклицательным знаком, установите драйвер производителя моста (WCH для CH34x,
Silicon Labs для CP210x).

Плата с прошивкой V0.9 beta или новее при включении появляется ещё и как
**USB Serial Device** — это порт, через который приложение с ней работает.

## 4. Обновление одной кнопкой

1. Подключите плату USB-кабелем.
2. Откройте приложение, вкладка **Быстрый старт**.
3. Нажмите **Найти плату**. В журнале появится строка вида
   `Плата на COM5: версия V0.9 beta, процесс остановлен, API-ключ получен.`
4. Нажмите **Обновить до последней версии** и подтвердите.

Приложение само:

- проверит, что процесс остановлен (если запущен — обновление не начнётся);
- скачает последний релиз и проверит его контрольные суммы;
- прошьёт плату: загрузчик, таблицу разделов, приложение и веб-интерфейс;
- после перезагрузки плата снова доступна по `automatika.local`.

Настройки, API-ключ и история процессов сохраняются.

Если кнопка **Найти плату** ничего не нашла, см. раздел 7.

### Порт прошивки

Поле **Порт прошивки** выбирается автоматически. Прошивка идёт через мост
CH34x/CP210x (или USB-JTAG). Если плата программируется через свой USB-порт
(JTAG), после первой прошивки с USB-CDC этот порт может стать недоступен.
В этом случае используйте порт моста или переведите плату в режим загрузки:
удерживайте BOOT, нажмите RESET и отпустите BOOT.

## 5. Обновление по Wi-Fi

Если USB-порта прошивки нет, приложение обновляет только программу устройства
по сети. Веб-интерфейс при этом не меняется. Чтобы обновить и его, подключите
плату по USB.

Для обновления по сети устройство и компьютер должны быть в одной сети, а API-ключ
уже сохранён (см. раздел 4, шаг 3).

## 6. Проверка скачанного файла

В PowerShell:

```powershell
Get-FileHash .\Automatika-v0.9.5-beta.exe -Algorithm SHA256
```

Сравните строку `Hash` с первой колонкой в `SHA256SUMS-app.txt`. Они должны
совпасть в нижнем регистре.

## 7. Если что-то не получилось

| Сообщение в журнале | Что сделать |
|---|---|
| `Плата Automatika по USB не найдена` | Проверьте кабель и драйвер моста. Плата должна быть с прошивкой V0.9 beta или новее. |
| `процесс запущен: остановите его перед обновлением` | Остановите процесс на экране платы или в веб-интерфейсе. |
| `опубликованных релизов пока нет` / `в последнем релизе нет архива прошивки` | Релиз ещё не собран. Подождите или скачайте прошивку вручную (раздел 8). |
| `нет доступа к GitHub` | Проверьте интернет и доступ к github.com. |
| `контрольная сумма не совпала` | Файл повреждён или подменён. Скачайте релиз заново. |
| `esptool завершился с ошибкой` | Проверьте, что выбран правильный порт, плата в режиме загрузки (BOOT+RESET) и кабель с передачей данных, а не только питания. |
| `не установлен pyserial` / `esptool` | Этот текст видно только при запуске из исходников: `pip install -r tools/configurator/requirements.txt`. |

## 8. Прошивка вручную

Если приложение не подходит, файлы прошивки есть в каждом релизе в архиве
`automatika-<версия>.zip`. Распакуйте его и используйте `esptool` или
`idf.py flash` (см. `SETUP.md`).

## 9. Безопасность

- API-ключ хранится в `%USERPROFILE%\.automatika\configurator.json` в открытом виде.
  Не копируйте этот файл на общие компьютеры.
- Любой, кто подключил плату по USB, может получить по команде `AUTOMATIKA?`
  её версию и API-ключ. Не подключайте плату к чужим компьютерам.
- Перед обновлением убедитесь, что процесс остановлен и E-STOP отпущен.

## Для разработчиков

Исходники: `tools/configurator/` (интерфейс, USB, релизы), точка входа —
`tools/automatika_app.py`. Сборка на своей машине:

```powershell
powershell -ExecutionPolicy Bypass -File tools\configurator\build_exe.ps1
```

В CI файл `Automatika.exe` собирается workflow `windows-app`
(`.github/workflows/app.yml`) и публикуется в релизе при каждом теге `v*`.
