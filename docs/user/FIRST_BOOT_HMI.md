# Чек-лист первого запуска HMI (Waveshare ESP32-S3-Touch-LCD-7)

Дата платы: **6 декабря 2026**. Ниже — порядок включения и что записывать.
Все значения записать в `/storage/emulated/0/Download/OpenCode/HMI/first_boot_log.txt`.

## 0. До включения

- [ ] Прошивка собрана: `cd firmware_hmi_project && idf.py build`.
- [ ] В `sdkconfig`: `FLASHSIZE_16MB`, `SPIRAM`, `SPIRAM_XIP_FROM_PSRAM`, `LV_COLOR_DEPTH_16`.
- [ ] Включены шрифты `CONFIG_LV_FONT_MONTSERRAT_12/14/16/18/20/24/28/32` (только для `LV_SYMBOL_*`).
- [ ] Кириллические `cyr_12…cyr_32` есть в `main/ui/fonts/` и пересобраны `tools/gen_fonts.sh`.
- [ ] RS485-A/RJ45 подключён: HMI `GPIO15 TXD`, `GPIO16 RXD`, земля с контроллером.
- [ ] Терминатор 120 Ом только на двух концах линии; экран не питает другое устройство.
- [ ] Контроллер прошит V1.0.1 с RS486-сервером (`RS485_BAUD 115200`, `RS485_POLL_MIN_MS 500`, timeout 100, retries 2, gap 2000).
- [ ] На контроллере выставлен snapshot телеметрии на каждый `POLL` (или генерация 2 Гц).

## 1. Питание и дисплей

- [ ] 5 V, ток ≈450 мА, нет просадки при подсветке.
- [ ] После power-on: логотип/чёрный экран → LVGL main за ~2–3 с.
- [ ] Разрешение 800×480, альбомная ориентация, нет «зеркала» и смещения.
- [ ] GT911: тап в центре → подсвечивается нужная кнопка, **без `320 - x`**.
- [ ] Проверить 4 угла экрана и свайп/удержание 2 с → возврат назад.
- [ ] Цвета: futuristic-палитра, жёлтые пороги, зелёный `ГОТОВ`, красный `E-STOP`.
- [ ] Нет засветки/полос на RGB; bounce lines = 10, PCLK 16 МГц.

## 2. Протокол (до реальной печи)

- [ ] Лог HMI: `UART1 115200 baud, TX=15 RX=16, poll=500 ms, timeout=100 ms`.
- [ ] Тестовый кадр из консоли/скрипта:
  `AA 55 00 00 01 00 20 01 63 6E` (CRC `0x6E63`) принят контроллером.
- [ ] Ответ `TELEMETRY (0x81)` приходит за <100 мс; в логе `frames` растёт, `crc_err=0`.
- [ ] За 10 с: ~20 кадров `POLL`, ~20 ответов, 0 CRC-ошибок.
- [ ] Задержка `latency_ms` в «Диагностике» разумна (обычно 5–15 мс).
- [ ] Отключить кабель на 2 с → «НЕТ СВЯЗИ»; подключить → связь восстановилась.
- [ ] После 3 пропусков (1.5 с) → `link=false`, но E-STOP/safety остаются видимыми.
- [ ] Повторы: 2; интервал между кадрами ≥2 мс (осциллограф/логический анализатор).
- [ ] При 115200 загрузка линии ≈4.4 %; при подозрении на помехи — временно 57600.

## 3. UI и телеметрия

- [ ] Главный экран: часы `ЧЧ:ММ:СС` идут; при `epoch` из телеметрии — синхронизируются.
- [ ] На всех экранах есть `?` и `fx` справа вверху; переход в Справку/Калькуляторы работает.
- [ ] Кириллица без «квадратов» на всех 216 экранах (проверьте `'Ректификация'`, `'Диагностика'`, `'Калькуляторы'`).
- [ ] `POLL` 2 Гц → значения обновляются 2 раза в секунду, без дублей от 1 Гц REST.
- [ ] Экран «Ректификация»: `ПАР=tc`, `УСТ=ts`, `ОТБОР=body`, график КУБ/ПАР.
- [ ] Экран «Подготовка»: `t1/t2/level/flow`, `sealed=sa`, `rinse_done=sd`.
- [ ] Экран «Диагностика»: RS485 OK, CRC=0, frames растёт, heap/PSRAM.
- [ ] Экран «Система»: версия `V1.0.1`, uptime, `api_ok=db`.
- [ ] `CMD` из UI → `ACK` с тем же `SEQ`; команда повтора не применяется дважды.

## 4. Производительность и память

- [ ] FPS: 30 (главный), 20 (график), 10 (меню 216 экранов), 2 (фон); записать.
- [ ] `lv_timer` 500 мс не блокирует тач; задержка ответа UI <100 мс.
- [ ] Heap free после 1 ч >30 КБ; PSRAM free >3 МБ; нет перезагрузок.
- [ ] IRAM не заполнен: RS485-задача использует read/poll без ISR в IRAM.
- [ ] Проверить I2C-сканирование: GT911, CH422G `0x24`/`0x38`, `0x20` свободен.

## 5. Safety (обязательно)

- [ ] Нажать E-STOP на контроллере → `es=1` на HMI в течение ≤1 с, нагрев снят.
- [ ] HMI **не пытается** снять E-STOP или обойти `safety_gate`.
- [ ] STOP/сброс аварии требуют подтверждения на экране.
- [ ] При обрыве RS485 контроллер сохраняет последнее безопасное состояние.
- [ ] Local LCD 480×320, PWA, Android и MQTT на контроллере работают как раньше.
