# Автоматика Autopilot — приложение для Android

«Автоматика Autopilot» показывает состояние аппарата и позволяет запускать,
останавливать процесс и сбрасывать аварию с телефона.

Если контроллер не подключён, приложение работает в **демо-режиме**: показывает
симулированный процесс дистилляции. Ничего не отправляется на устройство, даже
кнопки «Старт» и «Стоп» действуют только внутри приложения.

## 1. Установка

1. Скачайте `Autopilot-<версия>.apk` из последнего релиза:
   https://github.com/topsecret08/automatika_v2/releases/latest
2. Проверьте контрольную сумму по `SHA256SUMS-apk.txt` (по желанию).
3. Откройте файл на телефоне. Android попросит разрешить установку из
   неизвестного источника — разрешите для браузера или файлового менеджера.
4. Нажмите **Установить**.

Минимальная версия Android — 8.0 (API 26).

## 2. Первый запуск

Сразу после запуска вы увидите плашку **ДЕМО-РЕЖИМ**. Это нормально, если
контроллер ещё не подключён: можно познакомиться с интерфейсом.

## 3. Подключение к контроллеру

1. Подключите телефон к той же Wi-Fi сети, что и контроллер.
2. Откройте **Настройки**.
3. В поле **Адрес контроллера** введите `automatika.local` или IP-адрес
   из настроек роутера, например `192.168.1.50`.
4. В поле **API-ключ** введите ключ из веб-интерфейса (**Система → API-ключ**).
5. Выключите переключатель **Только демо-режим**, если он был включён.
6. Нажмите **Сохранить**.

Через несколько секунд плашка сменится на **Подключено к контроллеру (версия)**.
Если связи нет, приложение повторяет попытки и через пару секунд снова
переходит в демо-режим.

## 4. Управление

- **Старт** — запускает процесс. Доступно, если процесс остановлен и нет аварии.
- **Стоп** — останавливает процесс.
- **Сброс аварии** — появляется при аварии. Сначала остановите процесс,
  отпустите E-STOP и проверьте уровень жидкости, затем нажмите кнопку.

Сброс аварии во время процесса контроллер запрещает, и приложение покажет причину.

## 5. Демо-режим

- Включается автоматически, если контроллер не отвечает, или переключателем
  **Только демо-режим** в настройках.
- Значения рассчитываются по времени: куб постепенно нагревается, головы и тело
  накапливаются.
- Кнопка **Демо: имитировать аварию** останавливает процесс и блокирует запуск,
  пока не выполнен сброс аварии. Так можно проверить, как приложение ведёт себя
  при аварии.
- Демо-режим не управляет реальным оборудованием.

## 6. Безопасность

- API-ключ хранится на телефоне в настройках приложения. Не передавайте его
  другим людям и не используйте приложение на чужих телефонах.
- Передача идёт по локальной сети без шифрования (HTTP), как и в веб-интерфейсе
  контроллера. Не открывайте контроллер в интернет.
- Перед запуском процесса убедитесь, что аппарат готов, и E-STOP доступен.

## 7. Если что-то не работает

| Сообщение | Что сделать |
|---|---|
| `Контроллер не подключён (нет связи с http://…)` | Проверьте адрес, Wi-Fi и что контроллер включён. |
| `неверный API-ключ` | Проверьте ключ в веб-интерфейсе контроллера. |
| `авария: сначала сбросьте аварию` | Сбросьте аварию кнопкой «Сброс аварии». |
| `сначала остановите процесс` | Остановите процесс, затем сбросьте аварию. |
| Кнопки недоступны | Проверьте состояние процесса и аварии в блоке «Состояние». |

## Для разработчиков

Исходники: `android/` (Kotlin, Jetpack Compose, без сторонних сетевых библиотек).
Юнит-тесты: `gradle testDebugUnitTest` в папке `android/`. Сборка APK:
`gradle assembleDebug`. В CI workflow `android-app` (`.github/workflows/android.yml`)
собирает APK и прикрепляет его к релизу тега `v*`.
