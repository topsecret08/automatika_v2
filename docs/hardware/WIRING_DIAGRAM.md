# Схема подключения модулей

Текстовая схема ESP32-S3-DevKitC-1 N16R8. Источник истины — `main/config.h`;
при расхождении правьте этот файл по коду. Полная распиновка и предупреждения
— в [`pinout.md`](pinout.md).

## Примечания

- Нагрев: механический разрыв фазы E-STOP обязателен. Программная защёлка на
  GPIO 7 его не заменяет.
- Пины 7, 40 и 42 ещё не проверены на стенде: E-STOP, уровень и зуммер пока на
  макетной плате.
- Тач FT6336U работает только по I2C. Линии CTP_INT и CTP_RST не подключены.
- Схема силовой части зависит от вашего аппарата. Перед подключением 220 В
  пройдите [`BEGINNER_GUIDE.md`](../user/BEGINNER_GUIDE.md).
