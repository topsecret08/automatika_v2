# Независимая аппаратная защита нагрева

> **Статус: эталонная схема, не проверенное изделие.** Документ описывает, как
> отключить нагреватель без участия прошивки. Схема не проверена на плате и не
> испытана. Перед подключением к сети 220 В её должен проверить инженер-электрик,
> и стенд должен пройти испытания из раздела 5.

## 1. Какую проблему решаем

Сейчас нагрев разрешает `hal_safety_relay` через GPIO `SAFETY_RELAY_GPIO`:
пока приходит heartbeat из задачи safety, GPIO = 1 и катушка NO-реле
включена.

Слабое место: если МК завис, GPIO сохраняет последнее состояние. Катушка
остаётся под напряжением, и нагреватель продолжает работать. Программная
защита здесь не помогает, потому что её исполнитель и есть то, что зависло.

Нужна цепь, которая без участия МК снимает питание катушки, если МК перестал
подтверждать работу.

## 2. Решение: сторожевой таймер с выходом сброса

Используется внешний таймер с функцией watchdog, например TPL5010 (Texas
Instruments). По datasheet:

- таймер ждёт сигнал **DONE** — переход низкий → высокий. Прошивка выдаёт его
  из задачи safety (`hal_ext_watchdog_kick()`, период 100 мс);
- если DONE не пришёл за интервал, таймер выдаёт низкий импульс **RSTn**
  длительностью около 320 мс. Интервал задаётся внешним резистором `REXT`
  по таблицам datasheet;
- сигнал WAKE не используется (можно вывести на вход МК для диагностики).

Цепь разрешения катушки строится так, чтобы катушка получала питание
**только если выполнены оба условия**:

- МК разрешает нагрев (GPIO `SAFETY_RELAY_GPIO` = 1);
- линия RSTn в высоком уровне (таймер не сработал).

## 3. Эталонная схема

```
   +12 В ──┬──── катушка NO-реле ────┐
           │                          │
           └──── диод (встречный) ────┤  (диод параллельно катушке)
                                      │
                               сток Q1 (N-MOSFET)
                                      │
                               исток Q1 = сток Q2
                                      │
                               исток Q2 (N-MOSFET)
                                      │
                                     GND

   Затвор Q1  ◄── GPIO SAFETY_RELAY_GPIO (через 100 Ом)
   Затвор Q2  ◄── линия RSTn таймера, высокий уровень = разрешено
                  (RSTn подтянут к +3.3 В резистором Rp по datasheet)

   Подтяжки затворов к GND, 100 кОм — при старте и без питания цепь выключена.
```

Ток катушки идёт, только если открыты **оба** транзистора: Q1 по команде МК
и Q2 при нормальном RSTn. Если таймер сработал или МК завис, хотя бы один
транзистор закрывается, и катушка обесточивается.

Значения номиналов, тип реле и MOSFET, сечения и предохранители выбирает
инженер по своим компонентам. Схема выше показывает логику, а не готовый
номинал.

Силовая цепь 220 В остаётся за NO-контактом реле, как и раньше
(см. `docs/user/BEGINNER_GUIDE.md`, часть 2.4).

## 4. Прошивка

- `EXT_WDT_DONE_GPIO` в `main/config.h` — вывод DONE. По умолчанию `-1`:
  плата работает как раньше, линия не задействована.
- `hal_ext_watchdog_init()` вызывается при старте, `hal_ext_watchdog_kick()` —
  из задачи safety каждые 100 мс.
- Интервал таймера должен быть больше периода задачи safety с запасом. Для
  интервала около 1 с период 100 мс подходит.

Включать `EXT_WDT_DONE_GPIO` можно только после того, как схема собрана и
испытания из раздела 5 пройдены.

## 5. Испытания перед включением в работу

Схема должна пройти все сценарии. Результаты записываются в протокол.

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Нормальная работа, нагреватель отключён, таймер работает | Катушка включена только после разрешения от МК |
| 2 | Остановка МК отладчиком (halt) | Через интервал + 320 мс RSTn низкий, катушка выключена |
| 3 | Перезагрузка МК кнопкой RESET | Катушка выключена сразу, включается только после нового разрешения |
| 4 | Пропадание питания МК при подключённом 12 В | Катушка выключена (Q1 без управления) |
| 5 | Отключение линии DONE | Срабатывание как в п. 2, в журнал пишется событие |
| 6 | Короткое замыкание на затворе или отказ Q2 | Катушка не включается; отказ обнаруживается по readback |
| 7 | E-STOP во время нагрева | Нагрев снимается программно, контакт реле размыкается |

Испытания проводятся с отключённым нагревателем, затем под нагрузкой, с
контролем тока катушки и напряжения RSTn осциллографом.

## 6. Что эта схема не закрывает

- Отказ самого таймера или выход из строя реле «залипанием» контактов.
  Для этого нужен анализ видов отказов (FMEA) и, возможно, второе реле.
- Ошибки прошивки, которые не останавливают задачу safety. Таймер ловит
  зависание, а не неверные команды.
- Монтаж, заземление и УЗО. Это отдельная часть электробезопасности.

## 7. Перед использованием

1. Схема собрана по этому документу, номиналы подобраны инженером.
2. Все сценарии из раздела 5 пройдены, протокол сохранён.
3. `EXT_WDT_DONE_GPIO` задан в `config.h` и прошивка собрана с ним.
4. Аппарат работал на стенде не менее одного полного процесса без сбоев.
