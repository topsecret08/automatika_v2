# Распиновка Automatika (ESP32-S3)

Источник истины — [`main/config.h`](../../main/config.h). Схемы ниже
отражают актуальную разводку контроллера V1.0.1. Если что-то расходится,
правьте `config.h`, а не этот документ.

## 2. ПВД-регулятор (SSR/MOSFET)

| Параметр | Где задаётся | По умолчанию |
|---|---|---|
| Тип регулятора | `reg_type` в NVS, PWA/LCD/REST | `0` (аналоговый DAC) |
| PWM GPIO | `reg_gpio` в NVS, PWA/LCD/REST | `14` (`REG_SSR_GPIO`) |
| Частота | `reg_freq` в NVS | `1000` Гц |
| Разрешение | `reg_res` в NVS | `10` бит |
| Инверсия | `reg_inv` в NVS | выключена |
| UART baud | `reg_baud` в NVS | `9600` |
| Аналоговый диапазон | `ana_range` в NVS | `0–5 В` |
| Аналоговый 0 % | `ana_min` в NVS | `0 %` duty |
| Аналоговый макс. | `ana_max` в NVS | `100 %` duty |
| Закон мощности | `ana_sqrt` в NVS | `sqrt(U)` |

Доступные для ручного выбора PWM-выводы: **14, 41, 47, 48** (при свободности
по текущей конфигурации; 15–18,21 зарезервированы под RS485/дозатор). USB/UART0,
strapping и диапазон 26–37 запрещены; при недопустимом выводе
`regulator_ready=false`, выход 0, и API/PWA сообщают ошибку. Источник истины
списка — `main/control/regulator_settings_logic.h`.

5 В напрямую с GPIO ESP32-S3 не выдавать. Для AC SSR использовать zero-cross
или подходящий драйвер/оптрон. Прямое подключение 0/25/50/75/100 % PWM к AC SSR
без согласования недопустимо.

### 2.1. Finglai SSVR: PWM → 0–5 В → CONT/COM

```
ESP32-S3 LEDC (3,3 В PWM) → преобразователь PWM→аналог → 0–5 В
         → SSVR CONT (+) / COM (−)
```

- Это **не** прямое подключение GPIO к SSVR и **не** замена однофазному SSR.
- Клеммы **+5V** и **4–20 mA** SSVR в режиме 0–5 В не используются.
- Питание преобразователя — отдельное, с гальванической развязкой.
  Выход 5 В преобразователя нельзя заводить на GPIO ESP32.
- Калибровка: `ana_min`/`ana_max` по фактическому напряжению 0 В и полной
  шкале; `ana_sqrt` включает аппроксимацию `P ∝ U²`.

## 3. I2C-устройства

| Адрес | Устройство | Назначение | Обязательно |
|---:|---|---|---|
| `0x11` | Grove 4-Channel SSR | реле 0–3: охлаждение, вода, мешалка, резерв | да |
| `0x40` | PCA9685 | клапаны HEADS/BODY/TAILS + дефлегматор | да |
| `0x48` | ADS1115 | давление (A0), вакуум (A1), пролив (A2), пары (A3) | опционально |
| `0x60` | MCP4725 | аналоговый сигнал 0–3.3 В на SSR нагрева | да |
| `0x68` | DS3231 | RTC, резервная батарея CR2032 | опционально |
| `0x77` | BMP280 | давление/температура для поправки кипения | опционально |

> Адрес BMP280 может быть `0x76` при низком уровне SDO. Прошивка использует
> `0x77`; при другой сборке поправьте `I2C_ADDR_BMP280`.

## 4. Силовые цепи

| Цепь | Коммутация | Примечание |
|---|---|---|
| Нагреватель 220 В | SSR 40 A; управление 0–3,3 В от MCP4725 **или** PWM GPIO через оптрон/драйвер | радиатор обязателен; для AC SSR проверить тип входа/частоту |
| Аварийный разрыв | E-STOP механически разрывает фазный провод | GPIO 7 — только сигнал, не безопасность |
| Охлаждение/вода/мешалка | Grove SSR (I2C) | гальваническая развязка модуля |
| Клапаны/дефлегматор | PCA9685 → MOSFET/сервоприводы | питание клапанов отдельное |
| Насос отбора | A4988 + NEMA17 | STEP=`GPIO15`, EN=`GPIO16` по умолчанию headless |
| Соленоид | PWM/MOSFET | `GPIO41`, 25 Гц |
| Fail-safe реле | реле безопасности | `GPIO47` |
| Внешний WDT | DONE pulse | `GPIO48` |

**E-STOP обязателен как механический разрыв.** Программная защёлка на
GPIO 7 — дополнение для UI и журнала, а не замена аппаратной защиты.

## 5. Занятые и запрещённые пины

- **USB**: GPIO 19/20 (native USB), не занимать.
- **UART0**: GPIO 43 (TX) / 44 (RX), используется для логов и прошивки.
- **PSRAM Octal**: GPIO 33–37 заняты внутри модуля N16R8; GPIO 26–32
  обычно заняты SPI flash/PSRAM. Не использовать без проверки схемы.
- **Отсутствуют у ESP32-S3**: GPIO 22, 23, 24, 25.
- **Strapping**: 0, 3, 45, 46. Зуммер на 42, чтобы не занимать strapping-пин.
- **RS485 HMI**: GPIO 17/18/21 (UART2 TX/RX/DE).
- **HMI panel**: GPIO 15 TXD / 16 RXD на панели — не трогать.

## 6. Питание

- Вход: 220 В AC → предохранитель 5 A → варистор 275 В → EMI-фильтр →
  E-STOP → SSR/нагреватель и импульсный БП 5 В.
- Логика: 5 В → AMS1117 3.3 В для ESP32/датчиков, отдельная 5 В для
  клапанов/реле/насосов.
- Все GND соединены в одной точке, шина GND разделена на силовую и
  сигнальную.

## 7. Уровни безопасности

| Уровень | Средство | Действие |
|---|---|---|
| HW | Механический E-STOP | Разрыв фазы |
| HW | Поплавок уровня | Сигнал GPIO 40 + логическая блокировка |
| FW | Watchdog/сторож | Сброс нагрева, безопасное состояние |
| FW | Датчик пролива | Остановка процесса, тревога |
| SW | Пороги температуры/давления | Ограничение мощности, аварийный останов |
