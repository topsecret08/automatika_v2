# Распиновка Automatika (ESP32-S3)

Источник истины — [`main/config.h`](../../main/config.h). Таблица ниже
повторяет фактические значения прошивки V0.5 alfa. Если меняете плату,
меняйте `config.h`, а не этот документ.

## 1. GPIO

| GPIO | Функция | Режим | Примечание |
|---:|---|---|---|
| 1 | — | — | `PIN_SPILL_SENSOR` объявлен, но **не используется**: пролив читается с ADS1115 A2 |
| 2 | YF-S201 flow | input, IRQ | импульсы по фронту, 1–30 л/мин |
| 4 | 1-Wire DS18B20 | bidir | куб + царга, pull-up 4.7 кОм к 3.3 В |
| 5 | HX711 DOUT | input | тензодатчик |
| 6 | HX711 SCK | output | тензодатчик |
| 8 | I2C SDA | bidir | BMP280, DS3231, MCP4725, PCA9685, Grove SSR, ADS1115, FT6336 |
| 9 | I2C SCL | output | 400 кГц |
| 10 | microSD CS | output | SPI |
| 11 | microSD MOSI | output | SPI |
| 12 | microSD CLK | output | SPI |
| 13 | microSD MISO | input | SPI |
| 14 | LCD CS | output | ST7796 |
| 15 | LCD DC | output | ST7796 |
| 16 | LCD RST | output | ST7796 |
| 17 | LCD BL | output | подсветка, ШИМ |
| 18 | LCD MOSI | output | ST7796 (из-за него E-STOP не на 18) |
| 21 | LCD CLK | output | ST7796 |
| 27 | **E-STOP** | input, pull-up | НЗ-кнопка на GND; в норме 0, нажатие/обрыв — 1 |
| 28 | Level float | input, pull-up | поплавок, активный низкий |
| 38 | Touch CS (резерв) | — | FT6336 работает по I2C, линия не задействована |
| 39 | Touch IRQ | input | прерывание касания |
| 45 | Buzzer | output | активный 5 В через транзистор; strapping-пин, не тянуть вверх при старте |

> **У ESP32-S3 нет GPIO 22–25.** Это не «свободные» выводы, а отсутствующие
> в кристалле линии. `REG_SSR_GPIO` и `PUMP_STEP_GPIO` по умолчанию `-1`;
> реальные выводы задаются под конкретную плату. GPIO 26–32 на большинстве
> модулей заняты SPI flash/PSRAM, GPIO 33–37 — Octal PSRAM.

## 2. ШИМ-регулятор (SSR/MOSFET)

| Параметр | Где задаётся | По умолчанию |
|---|---|---|
| Тип | `reg_type` в NVS, PWA/LCD/REST | `0` (внутренний DAC) |
| PWM GPIO | `reg_gpio` в NVS, PWA/LCD/REST | `-1` (не задан) |
| Частота | `reg_freq` в NVS | `1000` Гц |
| Разрядность | `reg_res` в NVS | `10` бит |
| Полярность | `reg_inv` в NVS | активный высокий |
| UART baud | `reg_baud` в NVS | `9600` |

Прошивка разрешает только консервативный набор выводов: **7, 40, 41, 42,
47, 48**. Занятые проектом, USB/UART0, strapping и диапазон 26–37
отклоняются; при неверном значении `regulator_ready=false`, выход 0,
в API/PWA/LCD показывается причина. Для нестандартной платы список можно
расширить в `main/control/regulator_settings_logic.h` после проверки схемы.

Частота **не универсальна**. 5 кГц подходит только совместимому
MOSFET/DC-драйверу; для AC SSR обычно нужен zero-cross или иной режим
управления, которого в текущей прошивке может не быть. Выход ESP32-S3 —
3,3 В логика: проверьте входные требования SSR и обязательно используйте
оптронную/гальваническую развязку. До осциллографической проверки
(0/25/50/75/100 %) силовую часть не подключайте.

## 3. I2C-устройства

| Адрес | Устройство | Назначение | Обязательно |
|---:|---|---|---|
| `0x11` | Grove 4-Channel SSR | реле 0–3: охлаждение, вода, мешалка, резерв | да |
| `0x38` | FT6336 | ёмкостный тачскрин | да (для UI) |
| `0x40` | PCA9685 | клапаны HEADS/BODY/TAILS + дефлегматор | да |
| `0x48` | ADS1115 | давление (A0), вакуум (A1), пролив (A2), пары (A3) | опционально |
| `0x60` | MCP4725 | аналоговый сигнал 0–3.3 В на SSR нагрева | да |
| `0x68` | DS3231 | RTC, резервная батарея CR2032 | опционально |
| `0x77` | BMP280 | давление/температура для поправки кипения | опционально |

> Адрес BMP280 может быть `0x76` при низком уровне SDO. Прошивка использует
> `0x77`; при другой сборке поправьте `I2C_ADDR_BMP280`.

## 4. Силовые цепи

| Цепь | Коммутация | Примечание |
|---|---|---|
| Нагреватель 220 В | SSR 40 A; управление 0–3,3 В от MCP4725 **или** PWM GPIO через оптрон/драйвер | радиатор обязателен; для AC SSR проверить тип входа/частоту |
| Аварийный разрыв | E-STOP механически разрывает фазный провод | GPIO 27 — только сигнал, не безопасность |
| Охлаждение/вода/мешалка | Grove SSR (I2C) | гальваническая развязка модуля |
| Клапаны/дефлегматор | PCA9685 → MOSFET/сервоприводы | питание клапанов отдельное |
| Насос отбора | A4988 + NEMA17 | STEP/ENABLE по умолчанию `-1`; задайте реальные выводы |

**E-STOP обязателен как механический разрыв.** Программная защёлка на
GPIO 27 — дополнение для UI и журнала, а не замена аппаратной защиты.

## 5. Занятые и запрещённые пины

- **USB**: GPIO 19/20 (native USB), не занимать.
- **UART0**: GPIO 43 (TX) / 44 (RX), используется для логов и прошивки.
- **PSRAM Octal**: GPIO 33–37 заняты внутри модуля N16R8; GPIO 26–32
  обычно заняты SPI flash/PSRAM. Не использовать без проверки схемы.
- **Отсутствуют у ESP32-S3**: GPIO 22, 23, 24, 25.
- **Strapping**: 0, 3, 45, 46. GPIO 45 занят buzzer осознанно: при старте
  подтяжка должна быть вниз, иначе изменится режим загрузки.
- **LCD MOSI 18** — поэтому E-STOP перенесён на 27 (см. комментарий в
  `config.h`).
- **Энкодер KY-040/EC11** в текущей ревизии не разведён: `ENCODER_A_GPIO`,
  `ENCODER_B_GPIO`, `ENCODER_BTN_GPIO` равны `-1`. Меню LCD работает
  тапом; после разводки укажите пины в `config.h`, и
  `ui_physical_poll_encoder()` начнёт передавать вращение/нажатия в
  `ui_menu_encoder_*`.

## 6. Питание

- Вход: 220 В AC → предохранитель 5 A → варистор 275 В → EMI-фильтр →
  E-STOP → SSR/нагреватель и импульсный БП 5 В.
- 5 В питает ESP32-модуль (через его LDO 3.3 В), LCD, Grove SSR, датчики.
- Общая земля сигнальной части — одна точка у БП; силовая земля не
  соединяется с сигнальной внутри корпуса.
- Сечение силовых проводов — не менее 1.5 мм², клеммы с защитой от
  случайного касания.
