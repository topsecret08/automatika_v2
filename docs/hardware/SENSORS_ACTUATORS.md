# Датчики и актуаторы (аппаратное расширение)

Документ описывает расширение контроллера Automatika: модуль MCP23017, второй ADS1115, XGZP6897D, PT-506, ZMPT101B×3, LSA PWM, шаговый двигатель с DIR, цифровые входы уровня. Источник истины — `main/config.h` и драйверы в `main/hal/`.

## I2C устройства

| Адрес | Устройство | Назначение | Примечание |
|---:|---|---|---|
| `0x48` | ADS1115 #1 | штатные аналоговые каналы (давление/вакуум/пролив/MQ-3) | существующий |
| `0x49` | ADS1115 #2 | PT-506 (A0), ZMPT101B фазы A1-A3 | отдельный модуль |
| `0x21` | MCP23017 | 8 SSR выходов (GPA) + 8 цифровых входов (GPB) | отдельный модуль расширения |
| `0x6D` | XGZP6897D | давление куба/захлеб | I2C, 100 kHz |
| `0x60` | MCP4725 | аналоговый выход | существующий |
| `0x77` | BMP280 | барометр | существующий |

Шина I2C: `GPIO8=SDA`, `GPIO9=SCL`, 400 kHz (XGZP читается в отдельной транзакции; при необходимости снизить скорость для стабильности).

## MCP23017 (0x21)

### GPA0-GPA7 — SSR выходы, active HIGH, safe state OFF

| Pin | Канал | Назначение | Константа |
|---|---:|---|---|
| GPA0 | 0 | Головы | `MCP23017_SSR_HEADS_CH` |
| GPA1 | 1 | Тело | `MCP23017_SSR_BODY_CH` |
| GPA2 | 2 | Хвосты | `MCP23017_SSR_TAILS_CH` |
| GPA3 | 3 | Мешалка | `MCP23017_SSR_STIRRER_CH` |
| GPA4 | 4 | Насос охлаждения | `MCP23017_SSR_COOLING_CH` |
| GPA5 | 5 | Насос перекачки флегмы | `MCP23017_SSR_PHLEGM_CH` |
| GPA6 | 6 | 3-фазное SSR 2-й ТЭН разгона | `MCP23017_SSR_BOOST_3PH_CH` |
| GPA7 | 7 | Резерв | `MCP23017_SSR_SPARE_CH` |

SSR-модуль 8 каналов, логика 3.3V совместима (`MCP23017_SSR_ACTIVE_HIGH=1`). При E-STOP/bench/fault все GPA выходы переводятся в OFF.

### GPB0-GPB7 — цифровые входы уровня (pull-up)

| Pin | Вход | Датчик | Константа |
|---|---:|---|---|
| GPB0 | 8 | XKC-Y25-V диоптр захлеб | `LEVEL_XKC_DIOPTER_MCP_PIN` |
| GPB1 | 9 | XKC-Y25-V приёмная ёмкость overflow / NBK empty | `LEVEL_XKC_RECEIVER_MCP_PIN` |
| GPB2 | 10 | Поплавок перекачки флегмы (магнит+геркон) | `LEVEL_PHLEGM_REED_MCP_PIN` |
| GPB3-GPB7 | 11-15 | резерв | — |

XKC-Y25-V: согласование 5V→3.3V делителем 10к+22к + RC-фильтр на входе MCP23017. Полярность/активный уровень настраиваются (`LEVEL_INPUT_ACTIVE_HIGH`, NVS в будущем). Дебаунс `LEVEL_INPUT_DEBOUNCE_MS=50`.

## Аналоговые датчики

### PT-506 4-20mA — давление рубашки ПВК

- Канал: ADS1115 #2, A0 (`PT506_ADS_CH=0`).
- Шунт: `165Ω 0.1%` (4mA→0.66V, 20mA→3.3V).
- Диапазон: `PT506_RANGE_BAR=10.0` (уточнить по датчику).
- Аварийный порог рубашки: `PT506_JACKET_MAX_BAR=1.5` (калибруется).
- Обрыв провода: грубо детектируется по току < ~2mA (`pt506_is_ready()`).

### ZMPT101B ×3 — напряжение фаз основного ТЭНа

- Каналы: ADS1115 #2 A1/A2/A3.
- Назначение: мониторинг/контроль RMS напряжения по фазам; регулировка Loncont LSA-TH3P40Y.
- Алгоритм: выборка окна, удаление DC, RMS по окну; по каждой фазе медианный фильтр (`ZMPT_MEDIAN_WINDOW=5`) + среднее арифметическое по 3 фазам для управляющего значения.
- Формула управляющего значения: `Vctrl = mean(median(Vrms_phase1), median(Vrms_phase2), median(Vrms_phase3))`.
- Ограничение: ADS1115 имеет ограниченную частоту выборки; текущая реализация подходит для грубого мониторинга. **До стендовой калибровки не использовать как точный контур регулирования LSA.** Калибровочный коэффициент `ZMPT_CALIB_DEFAULT`, планируется NVS-калибровка.
- Аварийные пороги мониторинга: `ZMPT_RMS_MIN_V=170`, `ZMPT_RMS_MAX_V=260`.

### XGZP6897D — давление куба/захлеб

- Адрес: `0x6D`, опрос `XGZP6897D_POLL_MS=200ms`.
- Диапазон: `XGZP6897D_RANGE_KPA=100` (уточнить по варианту датчика).
- Порог захлеба: `XGZP6897D_CHOKE_KPA=30` (калибруется).
- Примечание: формула преобразования raw→кПа зависит от конкретного варианта XGZP6897D; требуется стендовая проверка коэффициентов.

## Актуаторы

### Loncont LSA-TH3P40Y (основной ТЭН)

- Управление: `GPIO38`, LEDC PWM 2kHz, 10-bit, через внешний модуль PWM→0-5V/0-10V.
- Safe state: `PWM 0%` при E-STOP active, bench mode, fault, init fail.
- Регулировка по напряжению ZMPT: только после стендовой валидации RMS и калибровки.

### Шаговый двигатель (отбор / подача браги в NBK)

- `GPIO15=PUMP_STEP`, `GPIO16=PUMP_EN` (active low), `GPIO39=PUMP_DIR`.
- Один физический шаговик: режимы TAKEOFF (отбор) и NBK_FEED (подача браги в NBK) **взаимоисключающие**.
- Направление переключается только при остановленном дозаторе (`ctrl_dose_set_nbk_feed`).
- В bench/E-STOP blocked действия блокируются штатными guard-ами дозатора.

## E-STOP bench/sensor-only mode

- Режимы: `REQUIRED_NC` (default, fail-safe) и `SENSOR_ONLY_BENCH`.
- В `SENSOR_ONLY_BENCH`: контроллер запускается, датчики/телеметрия читаются и отображаются, все исполнительные действия заблокированы (`actions_blocked=true`), статус содержит причину.
- Физический E-STOP сохраняет приоритет. Bench mode не заменяет E-STOP для штатной эксплуатации.
- Reset аварии в bench mode запрещён (действия остаются заблокированы).

## Ограничения

- GPIO15/16 HMI-панели не трогаются (это на стороне панели; контроллер использует GPIO15/16 для STEP/EN в headless-конфигурации согласно pinout).
- CAN framing и safety thresholds не менялись без необходимости.
- Новые поля протокола/телеметрии добавлены обратно-совместимо.
- Перед полевым использованием: стендовая проверка LSA safe-state (0V/PWM 0%), калибровка PT-506, XGZP6897D, ZMPT101B, проверка полярностей XKC/геркона.
