# Finglai SSVR: PWM → аналог 0–5 В → CONT/COM

Документ описывает **отдельный** тракт управления трёхфазным SSVR.
Он не является инструкцией по прямой замене однофазного SSR 220 В.

## 1. Цепочка

```
ESP32-S3 LEDC PWM (3,3 В)
        │
        ▼
преобразователь PWM → аналог (0–5 В)
        │
        ▼
SSVR: CONT (+) / COM (−)
```

- PWM выходит только с GPIO ESP32-S3 (3,3 В логика).
- PWM подаётся на вход преобразователя, **не на SSVR**.
- Аналоговый выход преобразователя подключается к **CONT (+)** и
  **COM (−)** SSVR.
- Клеммы **+5V** и **4–20 mA** SSVR в режиме 0–5 В **не используются**
  (по руководству Finglai).
- **5 В на GPIO ESP32 подавать нельзя.**

## 2. Что подтверждено руководством Finglai

- SSVR управляется аналоговым сигналом, в том числе **0–5 В**.
- Для 0–5 В: «+» сигнала — **CONT**, «−» — **COM**.
- Клеммы **+5V** и **4–20 mA** в этом режиме не используются.
- Вход 0–5 В имеет входное сопротивление **более 30 кОм**.
- Регулировка выходного напряжения линейная (по руководству).
- SSVR трёхфазный, ~380 В; конкретная модель, ток, нагрузка и схема
  подключения должны быть сверены с шильдиком и руководством.

## 3. Что нужно подтвердить по преобразователю PWM → аналог

По листингу Ozon характеристики не считаются подтверждёнными. Перед
подключением проверить:

| Параметр | Требование / что сверить |
|---|---|
| Вход PWM | 3,3 В логика, частота проекта (по умолчанию 1 кГц), скважность 0–100 % |
| Питание | отдельный источник, напряжение/ток по документации модуля |
| Выход | выбранный диапазон 0–5 В (или 0–10/0–3,3 В), линейность |
| Нагрузка | вход SSVR >30 кОм; выход модуля должен её выдерживать |
| Развязка | гальваническая изоляция вход/выход/питание |
| Защита | поведение при обрыве PWM, ограничение выхода, помехи |
| Частота | если модуль не принимает 1 кГц — изменить `reg_freq` в допустимых пределах или согласовать вход |

Если документация модуля недоступна, эти пункты остаются обязательными
для стендовой проверки. Нельзя считать модуль совместимым только по
названию «PWM → 0–5 В».

## 4. Трёхфазная силовая часть

- SSVR ~380 В — это не однофазный SSR 220 В. Проверить:
  - точную модель и номинальное напряжение;
  - номинальный/пусковой ток нагрузки;
  - тип нагрузки (резистивная/индуктивная);
  - схему включения, фазировку, нейтраль, заземление;
  - охлаждение/радиатор, предохранители, УЗО/автомат;
  - отсутствие обратной связи с GPIO.
- Монтаж и пусконаладку выполняет квалифицированный персонал.
- До проверки модели и нагрузки силовую часть не включать.

## 5. Калибровка и проверка

1. Отключить силовую часть, оставить преобразователь и измерительные
   приборы.
2. Задать `analog_min_pct` так, чтобы выход преобразователя был 0 В.
3. Задать `analog_max_pct` так, чтобы выход был полной шкалой (например,
   5 В).
4. Проверить 0/25/50/75/100 % команды по напряжению.
5. Включить `ssvr_power_sqrt`, если процент интерфейса означает
   электрическую мощность резистивного нагревателя. Проверить 0/50/100 %
   по фактической мощности; при отклонении — калибровать.
6. Проверить аварийное обнуление: E-STOP, авария, «Стоп», низкий уровень,
   смена регулятора, ошибка драйвера.

## 6. Ограничения прошивки

- PWM GPIO по умолчанию `-1`; при недопустимом выводе
  `regulator_ready=false`, выход 0.
- Нет автоматического определения типа преобразователя и SSVR.
- Нет компенсации нелинейности SSVR; `sqrt` — начальная аппроксимация.
- Нет измерения фактического напряжения/тока SSVR; для защиты нужны
  внешние аппаратные средства.
- Программный E-STOP не заменяет механическое отключение.
