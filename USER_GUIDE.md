# Руководство пользователя

Актуальное руководство: [`docs/user/USER_GUIDE.md`](docs/user/USER_GUIDE.md).

Этот файл оставлен для старых ссылок. Старая копия в корне расходилась с
актуальной и содержала устаревший способ отключить расходомер (`flow_present`).
Отключить расходомер можно через `POST /api/hardware` с ключом:
`{"devices":{"flow":false}}`.
