# Automatika v2.9

Универсальная система управления для дистилляции, ректификации,
пивоварения, паровых процессов и брожения.

## Возможности
- 8 режимов работы
- 4 AI-модуля
- SQLite история
- USB-OTG + FOTA
- Web-интерфейс
- 100+ статей справки

## Оборудование
- ESP32-S3-N16R8
- ST7796 LCD 480×320
- DS18B20, ADS1115, PCA9685, HX711
- LSA-TH3P40Y
