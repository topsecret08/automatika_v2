# Automatika V1.0.1

Прошивка ESP32-S3 для управления процессами перегонки, ректификации,
пивоварения, ПВК, НБК, вакуумной и двойной перегонки и брожения. Управление
с сенсорного экрана 480×320, из веб-интерфейса, с Windows-конфигуратора и с
Android-приложения.

> **Внимание.** Прошивка управляет нагревателем 220 В. Устройство проверено
> сборкой, модульными тестами и симуляцией. Испытаний на реальном стенде с
> нагревателем не проводилось. Перед эксплуатацией пройдите испытания из
> [`docs/hardware/INDEPENDENT_WATCHDOG.md`](docs/hardware/INDEPENDENT_WATCHDOG.md)
> и правила электробезопасности из
> [`docs/user/BEGINNER_GUIDE.md`](docs/user/BEGINNER_GUIDE.md). Не оставляйте
> работающий аппарат без присмотра.

## Два устройства в одном репозитории

Корень проекта по-прежнему — **прошивка контроллера**. Графический пульт
вынесен на отдельную плату Waveshare ESP32-S3-Touch-LCD-7 и живёт в
`firmware_hmi_project/`. Общий протокол RS485 — в `protocol/`,
без git submodules.

| Проект | Каталог | Прошивка | Дисплей |
|---|---|---|---|
| Контроллер | `.` | `automatika_v2.bin` | ST7796 480×320 |
| HMI-панель | `firmware_hmi_project/` | `hmi_panel.bin` | RGB 800×480 |

Панель — master шины и не выполняет safety-логику. E-STOP и `safety_gate`
остаются на контроллере. Подробности:
[`docs/developer/MONOREPO.md`](docs/developer/MONOREPO.md),
[`docs/developer/RS485_PROTOCOL.md`](docs/developer/RS485_PROTOCOL.md),
[`docs/FLASHING.md`](docs/FLASHING.md).

## Что умеет Автоматика

Контроллер ведёт процесс от нагрева до отбора фракций. Вы задаёте программу,
а Автоматика следит за температурой, давлением и безопасностью.

### Процессы

- 🔥 **Восемь процессов в одном устройстве:** дистилляция, ректификация,
  пивоварня, ПВК, НБК, вакуумная и двойная перегонка, брожение.
- 🎯 **Отбор по программе:** головы, тело и хвосты по заданным правилам
  и данным датчиков.

### Алгоритмы

- 🧮 **Адаптивный PID.** Регулятор нагрева подстраивается под аппарат.
  Автонастройка коэффициентов по методу Зиглера–Никольса.
- 🌡️ **Прогноз.** Скорость нагрева и время до заданной температуры.
- 📐 **Расчёт спирта.** Остаток этанола в кубе по температуре кипения
  и давлению (формула Антуана и таблица кипения).
- 🧪 **Выход на режим.** Ректификация ждёт стабилизации колонны по данным
  температуры.
- 🧹 **Фильтр выбросов.** Фильтр Хампеля отсекает помехи в показаниях АЦП.
- 🧠 **Память запусков.** Прошивка накапливает данные прошлых запусков.
- 🔬 **Экспериментально:** детектор аномалий (ИИ-модуль). Не используйте его
  как основную защиту.

### Безопасность и управление

- 🛑 **Безопасность в приоритете:** аварийная кнопка E-STOP, единая проверка
  перед каждым действием, аварийное реле, откат обновления при сбое. Без
  датчика куба старт запрещён (кроме ПВК и брожения). Поддерживается явный
  стендовый режим `SENSOR_ONLY_BENCH`: датчики/телеметрия читаются, все
  исполнительные действия заблокированы.
- 📱 **Управление откуда угодно:** экран 480×320, браузер, Android-приложение,
  Windows-конфигуратор, Telegram, MQTT, Blynk.
- 🔄 **Обновление в один клик:** по HTTPS (OTA) или через конфигуратор по USB.
- 🔓 **Открытый код:** лицензия MIT, логика, тесты и документация в репозитории.

### Датчики

| Величина | Датчик | Зачем |
|---|---|---|
| Температура куба и царги | DS18B20 | разрешение 0,0625 °C |
| Давление и вакуум | BMP280, ADS1115 | вакуумный режим, поправка температуры кипения |
| Давление куба / захлеб | XGZP6897D (I2C 0x6D) | контроль давления куба, порог захлеба |
| Давление рубашки ПВК | PT-506 4-20mA (ADS1115 #2) | контроль рубашки, аварийный порог |
| Напряжение фаз ТЭНа | ZMPT101B×3 (ADS1115 #2) | RMS мониторинг фаз, медиана+среднее по 3 фазам |
| Вес отбора | HX711 | учёт отобранного объёма |
| Расход воды | YF-S201 | контроль охлаждения |
| Уровень / overflow | поплавок, XKC-Y25-V, геркон флегмы (MCP23017) | защита нагрева, захлеб, переполнение/перекачка |

Устройство пока не сертифицировано, а испытаний с реальным нагревателем не
проводилось. Перед первым запуском прочтите предупреждение выше.

### Аппаратное расширение

- MCP23017 `0x21`: 8 SSR (головы/тело/хвосты/мешалка/охлаждение/насос флегмы/3-фазный ТЭН разгона/резерв) + цифровые входы уровня.
- ADS1115 #2 `0x49`: PT-506 4-20mA (рубашка ПВК) и ZMPT101B×3 (RMS фаз).
- XGZP6897D `0x6D`: давление куба/захлеб.
- GPIO38: LSA-TH3P40Y через внешний PWM→0-5/0-10V, safe state PWM 0%.
- GPIO39: DIR шаговика; один шаговик, TAKEOFF/NBK_FEED взаимоисключающие.

Подробности: [`docs/hardware/SENSORS_ACTUATORS.md`](docs/hardware/SENSORS_ACTUATORS.md), [`docs/hardware/SCHEMATIC_MODULES.md`](docs/hardware/SCHEMATIC_MODULES.md), [`docs/hardware/pinout.md`](docs/hardware/pinout.md).

## Известные ограничения

- Модули EQ_LOCK, VLE, PCHIP и zone_consensus есть в коде и тестах, но в рабочий
  цикл не подключены. Они не влияют на нагрев и отбор.
- Старт без датчика куба запрещён на всех путях запуска. Во время работы датчик
  может пропасть: тогда нагрев продолжится на заданной мощности (открытый пункт).
- Статус `degraded` (нет SD-карты или ни одного датчика DS18B20) сам по себе
  старт не блокирует. Старт без датчика куба запрещён отдельной проверкой.
- Выбор режима с пиктограммами есть в Android-приложении и в веб-интерфейсе.
  Двойная перегонка и брожение пока без пиктограмм.

Полный список с ссылками на код и пошаговыми действиями:
[`docs/KNOWN_LIMITATIONS.md`](docs/KNOWN_LIMITATIONS.md).

## Скачать

Все файлы публикуются в [последнем релизе](https://github.com/topsecret08/automatika_v2/releases/latest).

| Что | Файл в релизе | Инструкция |
|---|---|---|
| Приложение для Windows (прошивка по USB, обновление в один клик) | `Automatika-<версия>.exe` | [APP.md](docs/user/APP.md) |
| Приложение для Android (управление, демо-режим) | `Autopilot-<версия>.apk` | [AUTOPILOT_APP.md](docs/user/AUTOPILOT_APP.md) |
| Прошивка контроллера (архив) | `automatika-<версия>.zip` | [CONFIGURATOR.md](docs/user/CONFIGURATOR.md) |

Контрольные суммы — в `SHA256SUMS-app.txt`, `SHA256SUMS-apk.txt` и
`SHA256SUMS.txt` внутри архива прошивки. Проверка в PowerShell:

```powershell
Get-FileHash .\Autopilot-v0.9.7.apk -Algorithm SHA256
```

Сравните хеш со строкой в `SHA256SUMS-apk.txt`.

> **Внимание.** APK в релизах до `v0.9.8` подписан debug-ключом. Начиная с
> `v0.9.8` release-APK подписан ключом владельца репозитория.
> Прошивка по воздуху (OTA) принимается только с подписью ECDSA P-256:
> неподписанный или изменённый образ отклоняется. Первую прошивку с этой
> проверкой ставьте по USB. См. [`docs/developer/OTA_SIGNING.md`](docs/developer/OTA_SIGNING.md)
> и [`docs/SECURITY.md`](docs/SECURITY.md). Устанавливайте файлы только из
> официального релиза этого репозитория.

Подробности о работе — [`docs/user/USER_GUIDE.md`](docs/user/USER_GUIDE.md).

## Быстрый старт

1. Подключите оборудование по [`docs/hardware/pinout.md`](docs/hardware/pinout.md).
2. Прошейте плату: через приложение для Windows (см. [`APP.md`](docs/user/APP.md))
   или командой `idf.py flash` ([`SETUP.md`](SETUP.md)).
3. Настройте Wi-Fi и API-ключ: [`SETUP.md`](SETUP.md), раздел 6.
4. Управляйте с экрана, из браузера (`http://automatika.local/`) или
   из приложения.

Пошаговая инструкция для новичков: [`docs/user/BEGINNER_GUIDE.md`](docs/user/BEGINNER_GUIDE.md).

## Разработка

Требуется ESP-IDF v5.3.x (цель `esp32s3`). Сборка и тесты:

```bash
idf.py set-target esp32s3
idf.py build
idf.py -C test build                       # модульные тесты (Unity)
python test/qemu/run_qemu_tests.py --build-dir test/build
cmake -S test/host -B test/host/build && cmake --build test/host/build
ctest --test-dir test/host/build --output-on-failure
```

Подробно — [`SETUP.md`](SETUP.md) и [`docs/developer/BUILD.md`](docs/developer/BUILD.md).

Прочие инструменты:

- Windows-конфигуратор: `tools/configurator/` (сборка: `build_exe.ps1`);
- Android-приложение: `android/` (Gradle; дерево меню генерируется из
  `main/core/menu_tree.c` скриптом `tools/gen_android_menu.py`);
- тесты интерфейса: `python -m pytest tools/e2e`.

CI (`.github/workflows/`): сборка прошивки, модульные тесты в QEMU,
cppcheck, CodeQL, E2E-тесты интерфейса, сборка `Automatika.exe` и APK,
публикация релиза по тегу `v*`.
