# Automatika v2.9

Универсальная система управления технологическими процессами на ESP32-S3:
дистилляция, ректификация, пивоварение, паровые процессы (ПВК, НБК),
вакуумная перегонка, двойная дистилляция и брожение.

## Возможности

- **8 режимов работы** с автопилотом и профилями
- **4 AI-модуля**: предсказание страниц, предсказание действий,
  детектор аномалий, TinyML-модель
- **SQLite** в PSRAM: история процессов, графики, экспорт
- **Календарь и уведомления**: Wi-Fi, MQTT, Telegram, Алиса
- **Web-интерфейс** и REST API
- **USB-OTG**: Mass Storage + CDC
- **FOTA**: обновление по URL, с SD-карты и по QR-коду
- **Watchdog** на 10 задачах и распределение по двум ядрам
- **100+ статей справки**, уроки, рецепты и схемы на SD-карте

## Оборудование

| Компонент | Назначение |
|---|---|
| ESP32-S3-N16R8 | MCU, 16 МБ flash, 8 МБ PSRAM (Octal) |
| ST7796 (480×320) | LCD, SPI |
| FT6336 | Тачскрин, I2C |
| DS18B20 | Датчики температуры, 1-Wire |
| ADS1115 | АЦП 16 бит |
| MCP4725 | ЦАП |
| PCA9685 | Сервоприводы клапанов |
| HX711 | Весы |
| Grove SSR / реле | Нагрев и насосы |

Распиновка — в [`main/config.h`](main/config.h).

## Структура проекта

```
main/
├── ai/         предсказание страниц/действий, аномалии, TinyML
├── assets/     встроенные JSON: калькуляторы, схемы, языки
├── control/    PID, нагрев, клапаны, безопасность, калибровки
├── core/       состояние, меню, роли, справка, обучение, рецепты, SD
├── db/         SQLite: схема, миграции, запросы, экспорт/импорт
├── hal/        I2C, 1-Wire, ADC/DAC, дисплей, тач, SD, USB, HX711
├── modes/      режимы работы и их колбэки
├── ota/        FOTA: URL, SD, QR, проверка образа
├── ui/         LVGL-экраны и построители
└── web/        HTTP-сервер, WebSocket, MQTT, Telegram, Алиса
```

## Сборка

Требуется **ESP-IDF v5.3.x** (минимум v5.2) и цель `esp32s3`.

```bash
idf.py set-target esp32s3
idf.py build
idf.py -p COM5 flash monitor
```

Подробно — в [`SETUP.md`](SETUP.md).

## SD-карта

Справка, рецепты, уроки и схемы генерируются скриптом:

```bash
python generate_sdcard.py
```

Скопируйте содержимое `sdcard/` в корень FAT32-карты. Без карты система
работает, но полная справка и библиотека рецептов недоступны — часть статей
встроена в прошивку.
