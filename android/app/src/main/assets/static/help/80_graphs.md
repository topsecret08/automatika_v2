# Графики

## Реального времени
- Окно: 5 мин / 1 час / 24 ч
- Темы: тёмная/светлая/янтарная
- Экспорт в CSV

## Из истории
- Выбор процесса из БД
- Масштабирование
- Наложение графиков

## Параметры
- T куба
- T царги
- Мощность
- Давление
- Поток

## Производительность
- 60 точек/сек
- Буфер 300 точек
- Хранение 24 ч в SQLite

## Управление
- Свайп — сдвиг окна
- Тап — увеличить точку
- Двойной тап — сброс

## Экспорт
- CSV для Excel
- PNG скриншот
- JSON для анализа
