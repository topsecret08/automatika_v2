# Демо-режим

## Назначение
Обучение без реального процесса.

## Сценарии
- Нормальный процесс
- Перегрев куба
- Нет потока воды
- Отказ датчика
- Утечка паров
- Разлитие

## Скорость
- 1× (реальное)
- 10× ускорение
- 60× (1 мин = 1 час)
- 600× (1 мин = 10 ч)

## Использование
1. Демо → Запустить тренировку
2. Выбрать режим
3. Выбрать скорость
4. Наблюдать

## Статистика
Пройдено сценариев, ошибок.

## Цель
Научиться реагировать на аварии.
