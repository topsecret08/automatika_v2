# Двойная дистилляция

## Для чего
Классика для виски, коньяка, рома.

## Этапы
1. 1-я — брага → спирт-сырец (30%)
2. 2-я — сырец → продукт (65%)
3. Отбор головы/тело/хвосты

## Пресеты
| Напиток | T 1-й | T 2-й |
|---------|-------|-------|
| Шотландский | 98°C | 92°C |
| Ирландский | 98°C | 90°C |
| Коньяк | 96°C | 88°C |
| Бурбон | 98°C | 92°C |
| Кальвадос | 96°C | 88°C |
| Ром | 97°C | 90°C |

## Метод Габриэля
Деление браги T1/T2. См. 11_gabriel.md.

## Выдержка
- Бочка: 3-15 лет
- Щепа: 3-12 месяцев
- Минимум: 6 месяцев
