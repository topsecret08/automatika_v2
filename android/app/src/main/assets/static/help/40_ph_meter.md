# pH-метр

## Применение
- Пивоварение (pH затора 5.2-5.6)
- Контроль воды
- Кислотность браги
- Контроль брожения

## Типы
- Лабораторный (точный)
- Промышленный (надёжный)
- С датчиком (проточный)

## Подключение
- Аналоговый выход → ADS1115
- Питание отдельно
- Экранированный кабель

## Калибровка
1. Раствор pH 4.0 → калибровка
2. Раствор pH 7.0 → проверка
3. Раствор pH 10.0 → проверка

## Диапазоны
- Затор: 5.2-5.6
- Сусло: 5.0-5.4
- Пиво: 4.0-4.5
- Вода: 6.0-7.5

## Точность
- Дешёвый: ±0.2 pH
- Средний: ±0.1 pH
- Лабораторный: ±0.01 pH

## Обслуживание
- Хранить в KCl растворе
- Калибровать раз в 2-4 недели
- Замена электрода раз в 6-12 мес

## Ошибки
- Сухой электрод → долгий отклик
- Загрязнение → сдвиг калибровки
- Помехи от насосов
