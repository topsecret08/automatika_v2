# FOTA — 4 источника

## 1. SD-карта (рекомендуется)
Скопируйте .bin на SD:
/sdcard/firmware/automatika_v0.5_alfa.bin
Меню → Прошивка → Из SD → выбрать.

## 2. USB-OTG
1. USB → MSC
2. Закинуть .bin на SD из ПК
3. FOTA → Из SD

## 3. HTTP/HTTPS
Указать URL:
http://example.com/firmware.bin
Автозагрузка и прошивка.

## 4. QR-код
QR содержит URL:
https://example.com/firmware.bin
Открыть камерой → скачать.

## Автоматический откат
Если после прошивки система не подтвердила
работоспособность за 60 сек — откат.

## Версии
Проверка версии до прошивки:
fota_check_version(url, out, max)

## Ошибки
- Не читается .bin → скачать заново
- Откат → неверный образ
- Не стартует → проверить GPIO
