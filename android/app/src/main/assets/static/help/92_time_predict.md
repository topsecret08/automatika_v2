# Прогноз времени

## Формула
t = (T_цель − T_тек) / (dT/dt)

## Точность
- Начало: ±30%
- У середины: ±15%
- У цели: ±5%
- С TinyML: ±8%

## ETA
Показывает время суток окончания:
- 18:45 — сегодня
- 02:30 (+1д) — завтра

## Требования
NTP для точного ETA.

## Экран
Мониторинг → Прогнозы.

## Показывает
- Прошедшее
- Осталось
- Общее
- Прогресс %
- ETA

## Применение
- Планирование сна
- Напоминания
- Отлучки
- Планирование работы
