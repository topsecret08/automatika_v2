# BrewFather

## Что это
Облачный сервис для пивоваров.

## Экспорт
- Название партии
- Дата
- Объём
- Плотность (OG/FG)
- Статистика
- Объёмы фракций
- Длительность

## Настройка
1. Получить User ID, API Key
2. Настройки → BrewFather
3. Ввести данные
4. Экспорт

## API
https://api.brewfather.app/v2/batches

## Автоэкспорт
После процесса (опционально).

## Импорт
Не поддерживается (только экспорт).

## Ошибки
- 401 → ключ
- 404 → неверный endpoint
- Таймаут → сеть
