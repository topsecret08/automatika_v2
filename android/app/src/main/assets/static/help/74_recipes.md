# Рецепты

## Базы
- Пиво: 90 рецептов
- Дистилляты: 30
- Брага: 20

## Формат
JSON в /sdcard/recipes/.

## Структура пива

Пример JSON:

    {
      "id": "beer.ipa",
      "name": "Американский IPA",
      "og": 1.065,
      "fg": 1.014,
      "abv": 6.7,
      "ibu": 65,
      "srm": 8,
      "mash_temp": 65,
      "mash_min": 60
    }

## Свои рецепты
Создавайте, редактируйте, экспортируйте.

## Масштабирование
- По объёму
- По массе зерна
- Автоматически (85% варочника)

## Список покупок
Экспорт в TXT/CSV.
Печать.
