# Grove 4-Channel Solid State Relay

## Характеристики
- 4 канала
- SSR (без механических контактов)
- I2C 0x11 (или 0x12)
- Нагрузка: до 2 А (обычно)

## Подключение
- VCC → 3.3V
- GND → GND
- SDA → GPIO8
- SCL → GPIO9

## Каналы
- CH0: насос охлаждения
- CH1: клапан воды
- CH2: мешалка
- CH3: резерв

## Команда
2 байта: [0x01][маска]
Маска: бит 0-3 = каналы

## Управление
hal_relay_set(0, true) — включить насос
hal_relay_set(1, false) — закрыть клапан

## Применение
- Управление насосами
- Клапаны
- Мешалки
- Нагреватели

## Ошибки
- Не рассчитан на ТЭН 2+ кВт
- Для ТЭН нужен отдельный SSR на 40 А
- Проверять залипание раз в полгода
