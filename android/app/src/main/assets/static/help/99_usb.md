# USB-OTG

## Режимы
- MSC — SD как флешка
- CDC — виртуальный COM
- Оба — MSC + CDC
- Выкл — USB не активен

## Подключение
Порт USB (не UART!).
GPIO19 (D-), GPIO20 (D+).

## Использование MSC
1. USB → MSC
2. Подключить USB кабель к ПК
3. Появится диск «Automatika»
4. Копировать файлы

## Использование CDC
Виртуальный COM-порт для отладки.

## Ограничение
USB-Serial/JTAG и USB-OTG
используют одни пины.
Нужен переключатель.

## Ошибки
- Не видно на ПК → кабель
- Отключается → питание
- Ошибки копирования → скорость
