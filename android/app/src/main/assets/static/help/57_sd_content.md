# Контент SD

## Структура
- /help/*.md — 103 статьи
- /recipes/*.json — 140+ рецептов
- /lessons/*.json — 21 урок
- /schemes/*.json — 7 схем
- /calc/*.json — 8 калькуляторов
- /lang/*.json — 3 языка

## Автогенерация
При первом запуске всё создаётся автоматически.
Маркер: /sdcard/help/.generated

## Обновление
Можно перезаписать вручную — система подхватит.
Формат — Markdown или JSON.

## Проверка целостности
sd_content_verify_help() — проверяет все файлы.

## Ошибки
- Файл не читается → проверить кодировку (UTF-8)
- Ошибка JSON → проверить структуру
- Медленно → карта класса 4
