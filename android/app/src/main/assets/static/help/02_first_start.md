# Первое включение

## Шаги
1. Вставьте SD-карту (FAT32, 8+ ГБ)
2. При первом включении система создаст весь контент
3. Появится приветствие: «Что будем сегодня делать?»
4. Проверьте I2C: Диагностика → I2C-сканер
5. Установите PIN администратора (по умолчанию 3333)
6. Настройте Wi-Fi (можно сканированием QR)
7. Калибруйте датчики
8. Выберите первый режим

## Чек-лист
- Датчики DS18B20 видны
- Весы HX711 реагируют
- Реле щёлкают
- Клапаны двигаются
- Насос работает
- ТЭН управляется

## Первый процесс
1. Залейте 20 л сахарной браги
2. Подключите охлаждение
3. Меню → Режимы → Дистилляция
4. Уставка 98°C, отбор 30 мл/мин
5. Нажмите СТАРТ
