# PID-регулятор

## Формула
u(t) = Kp·e(t) + Ki·∫e·dt + Kd·de/dt

## Компоненты
- P — реакция на текущую ошибку
- I — на накопленную
- D — на скорость изменения

## Где используется
- Термостатирование брожения
- Пивоварение (паузы)
- ПВК (рубашка)

## Где НЕ используется
- Ректификация — постоянная мощность
- Дистилляция — фиксированные ступени

## Параметры
Kp = 15, Ki = 0.5, Kd = 2 (для типичного куба)

## Настройка
1. Начать с Kp = 10, Ki = 0.1, Kd = 0
2. Увеличивать Kp до колебаний
3. Добавить Ki для устранения смещения
4. Добавить Kd для сглаживания
