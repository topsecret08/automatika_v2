# Автотюнинг PID

## Метод
Ziegler-Nichols релейный.

## Как работает
1. Регулятор даёт релейный сигнал (0/100%)
2. Измеряются колебания T
3. Определяется Ku и Tu
4. Kp/Ki/Kd по формулам Z-N

## Формулы
Kp = 0.6 × Ku
Ki = Kp / (0.5 × Tu)
Kd = Kp × 0.125 × Tu

## Запуск
Настройки → Автотюнинг PID → Запустить

## Длительность
10-15 минут. Требует остывший процесс.

## Результат
Kp, Ki, Kd сохраняются в NVS.

## Ошибки
- Не запускать на нагретом кубе
- Не отвлекать систему
- Следить за отсутствием аварий
