# OTA

## Способы
1. Web: /api/ota
2. FOTA из 4 источников

## Разделы
- factory — заводская
- ota_0, ota_1 — рабочие

## Обновление
curl -X POST --data-binary @firmware.bin http://IP/api/ota


## Безопасность
- Проверка CRC
- Автоматический откат
- PENDING_VERIFY 60 сек

## Что НЕ прерывается
- Процесс продолжается
- Данные сохраняются
- Настройки в NVS

## Ошибки
- Обрыв → откат
- Неверный файл → отказ
- Мало места → очистка
