# Порог аномалий

## Что это
Reconstruction error, при котором ситуация аномальна.

## Значения
- 5-10%: очень чувствительный
- 10-15%: рекомендуемый
- 15-25%: средний
- 25-50%: слабый

## Как выбрать
1. Начните с 15%
2. Много ложных → увеличить
3. Пропускает аварии → уменьшить
4. Через неделю — оптимум

## Отображение
- Норма: error < порог
- Предупреждение: error 1-2× порога
- Аномалия: error > 2× порога
