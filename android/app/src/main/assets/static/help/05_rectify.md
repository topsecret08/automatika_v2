# Ректификация

## Что это
Глубокая очистка через колонну. До 96.6%.

## Параметры
- T царги: 77-78°C
- Флегмовое число: 3-4
- Отбор: 0.5-1.5 л/ч
- Мощность: постоянная

## Этапы
1. Разгон — 80% до 70°C
2. Стабилизация — 15 мин
3. Головы — 5% отбор, 45%
4. Тело — рабочий отбор
5. Хвосты — 25% после 92°C

## Важно
PID НЕ используется! Только постоянная мощность.
Импульсный ШИМ даёт нестабильный поток.

## Преимущества
- Чистый спирт 96.6%
- Отсутствие сивушных
- Стабильное качество

## Недостатки
- Теряются ароматы
- Долго (4-8 часов)
- Требует колонны
