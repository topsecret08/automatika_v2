# Вакуумная дистилляция

## Принцип
При низком давлении T кипения падает.

| Давление | T кипения |
|----------|-----------|
| 1013 мбар | 78°C |
| 100 мбар | 40°C |
| 60 мбар | 30°C |
| 50 мбар | 28°C |

## Применение
- Джин — сохранение ароматов
- Эфирные масла
- Гидролаты
- Деалкоголизация
- Экстракты

## Пресеты
- Джин (100 мбар / 40°C)
- Эфирные масла (60 / 30)
- Гидролаты (80 / 35)
- Деалкоголизация (50 / 28)

## Оборудование
- Вакуумный насос
- Датчик вакуума (0-1000 мбар)
- Герметичная колонна

## Тест утечки
1. Закрыть клапаны
2. Насос на 1 мин
3. Отключить
4. Рост давления < 5 мбар/мин
