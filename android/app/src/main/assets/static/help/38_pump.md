# Насос охлаждения

## Типы
- Погружной (аквариумный) — дешёвый
- Магнитный — тихий
- Перистальтический — точный
- Центробежный — производительный

## Подключение
- Питание 12/220 В
- Управление → Grove SSR CH0

## Производительность
- Дистилляция: 1-3 л/мин
- Ректификация: 2-5 л/мин
- ПВК: 5-10 л/мин

## Схема работы
- Включение при нагреве > 60°C
- Interlock: если насос встал — СТОП
- Постоянная работа в активной фазе

## Датчик потока
YF-S201 контролирует:
- Наличие потока
- Объём прокачки
- Аварийный стоп при 0 л/мин

## Важно
- Никогда не отключать при нагреве!
- Проверять перед процессом
- Чистить от накипи

## Ошибки
- Не качает → воздух в системе
- Слабый поток → фильтр засорён
- Шум → износ подшипников
- Перегрев мотора → плохое охлаждение

## Обслуживание
Раз в 3 месяца — проверка и чистка.
Раз в год — замена уплотнителей.
