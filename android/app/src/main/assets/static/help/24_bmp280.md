# BMP280

## Характеристики
- Давление: 300-1100 гПа
- Точность: ±1 гПа
- T: -40…+85°C
- I2C: 0x77 (или 0x76)

## Подключение
- VCC → 3.3V
- GND → GND
- SDA → GPIO8
- SCL → GPIO9
- SDO → GND (0x76) или VCC (0x77)

## Применение
- Атмосферное давление для коррекции T кипения
- Дополнительный датчик T
- Прогноз погоды

## Коррекция
T кипения = 100 + (P - 1013) × 0.028°C

Пример: P = 1000 гПа
T кип = 100 + (-13) × 0.028 = 99.64°C

## Ошибки
- Без компенсации T врёт
- Плохая вентиляция — влага
- На улице — защита от воды
