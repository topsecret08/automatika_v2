# Словарь терминов

**Дистилляция** — простая перегонка
**Ректификация** — перегонка с колонной
**Головы** — первая фракция (не пить)
**Тело** — питьевая часть
**Хвосты** — последняя фракция
**Флегма** — сконденсированный пар
**Флегмовое число** — отношение
**Авто-92+** — формула снижения отбора
**Предекремент** — упреждающее снижение
**НБК** — непрерывная бражная колонна
**ПВК** — пароводяной котёл
**ABV** — объёмная доля спирта
**OG** — начальная плотность
**FG** — конечная плотность
**IBU** — горечь пива
**SRM** — цвет пива
**Мэш-аут** — пауза 78°C
**Гидромодуль** — вода/зерно
**Тара** — вес пустой ёмкости
**Калибровка** — настройка точности
