# История процессов (SQLite)

## Что хранится
- Все процессы
- Измерения во времени
- События
- Оценки 1-5 звёзд
- Заметки

## Файл
/sdcard/automatika.db

## Размер
~1 МБ на 20 процессов.
Через год активного использования — 20-50 МБ.

## SQL-запросы
SELECT * FROM processes
WHERE type=2 AND rating>=4
ORDER BY started_ms DESC;

## Экспорт
- CSV всех процессов
- JSON конкретного
- Backup всего файла

## Очистка
База данных → Очистить.
Требуется PIN админа.

## Обслуживание
VACUUM раз в месяц сжимает файл.
