# Восстановление

## Сценарий 1: пропало питание
При старте система обнаружит снапшот процесса:
- «Продолжить с места остановки»
- «Начать заново»

## Сценарий 2: сбой прошивки
Автоматический откат через 60 сек.
Если PENDING_VERIFY не подтверждён — boot в другой раздел.

## Сценарий 3: повреждение SD
Система работает без SD:
- Нет справки, рецептов
- Нет истории
Перегенерировать: Админ → Перегенерировать.

## Сценарий 4: сброс к заводским
Настройки → Полный сброс → PIN админа.
Сохраняются: рецепты, БД процессов.

## Сценарий 5: зависание
Watchdog перезагрузит критичные задачи.
Если не помогает — RST на плате.

## Сценарий 6: ошибка I2C
Проверить:
1. Питание 3.3 В
2. Подтяжка SDA/SCL (4.7 кΩ)
3. Адреса устройств
4. Диагностика → I2C-сканер
