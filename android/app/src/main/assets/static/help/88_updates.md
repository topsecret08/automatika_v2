# Обновления

## Проверка
Настройки → Прошивка → Версии.

## Способы
- SD-карта (рекомендуется)
- USB-OTG
- HTTP/HTTPS
- QR-код

## История
- v2.0 — базовая
- v2.5 — AI-модули
- v2.7 — SQLite, USB, FOTA
- V0.5 alfa — полная справка

## Откат
Если не работает — «Прошивка → Откат».

## Сохранение данных
- Настройки в NVS
- БД процессов не теряется
- Пользовательские рецепты сохраняются

## Автообновление
Проверка раз в неделю (если Wi-Fi).

## Ошибки
- Не влезает → очистить разделы
- Скачивание долгое → SD-карта
- Не стартует → RST + BOOT
