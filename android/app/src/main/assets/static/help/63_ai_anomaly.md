# Детектор аномалий

## Что это
Автоэнкодер 8→4→8 на нормальных данных.
Высокий reconstruction error → аномалия.

## Входы
1. T куба
2. T царги
3. T рубашки
4. Давление
5. Мощность
6. Клапан тела
7. Поток
8. dT/dt

## Что ловит
- Перегрев
- Высокое давление
- Скачки T
- Падение потока
- Отказ датчиков
- Нестандартное поведение

## Срабатывание
→ Уведомление UI
→ Событие в журнал
→ Push в Telegram
→ Опционально: стоп

## Обучение
Только на нормальных данных.
Чем больше процессов — тем точнее.

## Порог
AI → Порог аномалий → 5-50%.
По умолчанию 15%.

## Точность
Precision 80-95% после 100 процессов.
