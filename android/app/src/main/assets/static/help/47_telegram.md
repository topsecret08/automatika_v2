# Telegram-бот

## Возможности
- Push при аварии
- Команды /status, /stop, /start
- Фото-скриншот /screenshot
- Графики после процесса

## Настройка
1. Создать бота в @BotFather
2. Скопировать токен
3. Указать Chat ID
4. Ввести в настройках

## Пример запроса
GET https://api.telegram.org/bot{TOKEN}/sendMessage
?chat_id={CHAT}&text={MESSAGE}

## Команды
- /start — приветствие
- /status — текущее состояние
- /stop — остановить
- /power 65 — установить мощность
- /graph — график процесса

## Уведомления
- Авария → немедленно
- Конец процесса → с отчётом
- Низкий уровень воды
- Ошибки датчиков

## Ошибки
- Не приходит → Chat ID
- Спам → настройки фильтра
- Не отправляет фото → токен
