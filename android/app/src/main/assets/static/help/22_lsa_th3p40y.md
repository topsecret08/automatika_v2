# LSA-TH3P40Y

## Характеристики
- 3-фазный симисторный регулятор
- 40 А
- Управление: 4-20 мА / 0-5 В / 0-10 В

## Подключение
- Управление ← MCP4725 (0-5 В)
- Вход 220V ← Сеть
- Выход → ТЭН

## Принцип
Регулятор изменяет фазу открытия симистора
по аналоговому сигналу.

## Управление от ESP32
ESP32 → MCP4725 (I2C) → LSA
0% = 0 В, 100% = 5 В

## Важно
- Только плавное управление
- БЕЗ ШИМ (для ректификации критично)
- Хорошее охлаждение (радиатор)
- Защита от КЗ

## Безопасность
- 220V на клеммах!
- Изоляция
- Заземление
- Автоматический выключатель
