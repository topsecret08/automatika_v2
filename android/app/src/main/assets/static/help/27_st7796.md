# ST7796 — LCD 3.5" IPS

## Характеристики
- 480×320 пикселей
- SPI интерфейс
- 16-bit цвет
- Подсветка: PWM

## Подключение (SPI2)
- VCC → 3.3V
- GND → GND
- CS → GPIO14
- DC → GPIO15
- RST → GPIO16
- BL → GPIO17 (PWM)
- MOSI → GPIO18
- CLK → GPIO21

## Драйвер
LovyanGFX + LVGL 8.3

## Инициализация
1. spi_bus_initialize(SPI2)
2. esp_lcd_new_panel_io_spi
3. esp_lcd_new_panel_st7796
4. reset, init, invert
5. swap_xy, mirror

## Цвета
- Color space: BGR
- LV_COLOR_16_SWAP=y

## Ошибки
- Белый экран → проверить RST
- Полосы → инверсия цвета
- Мигает → питание
- Не реагирует на тач → проверить IRQ
