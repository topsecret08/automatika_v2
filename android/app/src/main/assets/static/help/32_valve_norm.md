# НО/НЗ клапаны

## НЗ (Normally Closed)
- 0% сигнала → закрыт
- 100% сигнала → открыт
- Безопасно при потере питания

## НО (Normally Open)
- 0% сигнала → открыт
- 100% сигнала → закрыт
- Для сброса давления

## Выбор
| Назначение | Тип |
|-----------|-----|
| Клапан отбора тела | НЗ |
| Клапан голов | НЗ |
| Клапан хвостов | НЗ |
| Аварийный сброс | НО |
| Воздушный вентиль | НО |

## Управление в коде
valve_config_t содержит:
- norm: VALVE_NORMALLY_CLOSED/OPEN
- invert: инверсия сигнала

## Логика
effective_pct = norm==НЗ ? pct : (100 - pct)
if (invert) effective_pct = 100 - effective_pct
servo_angle = angle_min + effective/100 × (max-min)


## Проверка
1. Подать 0% → должен быть закрыт (НЗ)
2. Подать 100% → открыт
3. Отключить питание → закрыт (НЗ)

## Ошибки
- Клапан жужжит → мёртвая зона
- Не закрывается → калибровка углов
- Течёт → замена уплотнителя
