# HX711 (весы)

## Характеристики
- 24-бит АЦП
- Усиление: 32/64/128
- Частота: 10/80 Гц
- Bit-bang (2 пина)

## Подключение
- VCC → 3.3V или 5V
- GND → GND
- DOUT → GPIO5
- SCK → GPIO6
- E+/E- → питание тензодатчика
- A+/A- → сигнал

## Тензодатчики
- Балка: 1-50 кг
- Платформа: до 200 кг
- Монтаж: жёсткое основание

## Калибровка
1. Убрать всё с весов
2. Нажать «Тара» (offset)
3. Положить эталон 100 г
4. «Калибровать 100 г»

scale = (raw - offset) / 100

## Формула
grams = (raw - offset) / scale

## Ошибки
- Питание от 5V → нужен преобразователь уровней
- Плохой контакт A+/A- → шум
- Вибрация → нестабильные показания
- 80 Гц режим → меньше шума, но медленнее
