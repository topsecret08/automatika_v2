# Схемы установок

## Доступные
- Дистилляция
- Ректификация
- Пивоварня
- ПВК
- НБК
- Вакуум
- Двойная

## Формат
JSON с примитивами:
- rect (прямоугольник)
- circle (круг)
- line (линия)
- text (надпись)
- flow (поток)

## Отрисовка
LVGL canvas 480×320.
Zoom, панорама.

## Диагностика
Клик на элемент → детали.
Значения датчиков на схеме.

## Создание своих
Редактировать JSON в /sdcard/schemes/.

## Пример
{
  "title": "Дистилляция",
  "shapes": [
    {"t":"rect","x":80,"y":150,"w":120,"h":100,
     "c":"#555","label":"Куб"}
  ]
}
