# История из БД

## Что показывает
Список всех процессов с деталями.

## Действия
- Открыть детали
- График процесса
- Оценка 1-5 звёзд
- Заметки
- Экспорт
- Удалить

## Фильтры
- По типу
- По дате
- По рейтингу
- По длительности

## Сортировка
- По дате (новые/старые)
- По рейтингу
- По длительности

## Экспорт
- CSV всех
- JSON одного
- PDF отчёта

## Применение
- Анализ эффективности
- Сравнение процессов
- Улучшение рецептов
