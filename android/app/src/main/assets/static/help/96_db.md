# SQLite база данных

## Что хранится
- Процессы
- Измерения во времени
- События
- Рецепты
- История автообучения

## Файл
/sdcard/automatika.db

## Память
Кэш страниц в PSRAM (8 МБ).
Основные данные — на SD.

## Схема
- processes (главная)
- measurements (графики)
- events (журнал)
- recipes (пользовательские)
- autolearn_history

## SQL-запросы
Полноценный SQL через sqlite3.

## Обслуживание
VACUUM — раз в месяц.
Backup — раз в неделю.

## Ошибки
- Медленно → не хватает PSRAM
- Битый файл → восстановить из backup
