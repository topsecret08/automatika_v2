# Wi-Fi

## Настройка
1. Настройки → Wi-Fi → SSID
2. Пароль
3. DHCP или статический IP

## Быстрая настройка
Сканируйте QR:
Меню → QR-коды → Wi-Fi QR

## Режимы
- STA (клиент) — обычный
- AP (точка доступа) — при первом запуске
- STA+AP — оба

## Дополнительно
- mDNS: automatika.local
- NTP: pool.ntp.org
- Web: http://IP/

## Ошибки
- Не подключается → пароль
- Слабый сигнал → антенна
- 5 ГГц не поддерживается
- DHCP не выдаёт IP → статика

## Безопасность
- WPA2 минимум
- Не используйте открытые сети
- API-токен для Web
