# AI-модули системы

## 4 нейросети
1. **Предсказание экранов** — Markov + NN
2. **Предсказание действий** — что вы измените
3. **Детектор аномалий** — автоэнкодер
4. **TinyML** — прогноз времени

## Память
- Все модели: ~50 КБ PSRAM
- Кэш экранов: до 2 МБ PSRAM
- Обучение: ~3 мс / 30 сек

## Ускорение
PIE (SIMD int8): инференс 50-200 мкс.

## Работает офлайн
Данные не уходят в сеть.

## Обучение
Автоматически на ваших данных.
SGD on-device.

## Экспорт
На SD для переноса.

## Отключение
AI → AI-кэш: OFF
Или полное отключение через сброс.
