# Тензодатчик + HX711

## Что это
Датчик веса на основе тензорезисторов.

## Типы
- Балка (1-50 кг) — универсальный
- Платформа (до 200 кг) — для больших ёмкостей
- S-образный (5-5000 кг) — для подвеса
- Микро (0-1 кг) — для точных задач

## Подключение
- Красный — E+
- Чёрный — E−
- Белый — A+
- Зелёный — A−
- Экран — на GND

## Монтаж
- Один конец — на основание
- Второй — на платформу
- Жёсткое крепление
- Защита от боковых усилий

## Калибровка
1. Тара (offset)
2. Эталон 100 г
3. scale = (raw − offset) / 100

## Применение
- Точный отбор продукта
- Авто-калибровка клапанов
- Расчёт мл/ч
- Контроль потока

## Точность
- Дешёвый: ±1 г
- Средний: ±0.1 г
- Хороший: ±0.05 г

## Ошибки
- Температурный дрейф → рекалибровка
- Ползучесть → ждать 30 мин
- Вибрация → шум
- Влага → короткое замыкание
