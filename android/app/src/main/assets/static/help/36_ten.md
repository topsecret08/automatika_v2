# Нагревательный элемент (ТЭН)

## Типы
- ТЭН трубчатый — универсальный
- ТЭН в рубашке — для ПВК
- Сухой ТЭН — с воздушным охлаждением
- Погружной ТЭН — прямой контакт

## Мощность
- 2-3 кВт — домашние кубы 20-30 л
- 4-6 кВт — кубы 50+ л
- 8-12 кВт — промышленные

## Управление
Только через LSA-TH3P40Y (симисторный регулятор).
Для ректификации — **постоянная мощность**, без ШИМ.

## Подключение
- LSA выход → ТЭН (220V)
- LSA вход ← MCP4725 (0-5 В)
- Питание 220V через автомат 25 А

## Безопасность
- Заземление корпуса
- Автомат защиты
- Термопредохранитель в кубе
- Датчик наличия жидкости

## Ошибки
- Накипь снижает мощность
- Перегрев при работе без жидкости
- Плохой контакт клемм → искрение
- Не рассчитан на длительную 100%

## Обслуживание
Раз в месяц — чистка от накипи (лимонная кислота).
Раз в год — проверка сопротивления.
