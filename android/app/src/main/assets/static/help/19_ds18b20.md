# Датчик DS18B20

## Характеристики
- Паспортная точность: ±0.5°C при −10…+85°C; вне диапазона хуже (см. даташит)
- Погрешность после калибровки: проверяется эталоном, см. 101_sensor_calib.md
- Диапазон: -55…+125°C
- Разрешение: 0.0625°C (12 бит)
- Интерфейс: 1-Wire

## Подключение
- VCC → 3.3V (красный)
- GND → GND (чёрный)
- DQ → GPIO4 (жёлтый)
- Резистор 4.7 кΩ между DQ и 3.3V

## Несколько на шине
До 8 датчиков параллельно.
Один резистор на всю шину.

## Монтаж
- Гильза из нержавейки (для жидкостей)
- Термопаста
- Кабель экранированный (для дальних)

## Калибровка
Метод «горячая ванна»: все датчики в одну ёмкость.
См. 101_sensor_calib.md.

## Диагностика
- СКО шума < 0.01°C — отлично
- 0.01-0.05 — хорошо
- > 0.1 — плохой контакт
