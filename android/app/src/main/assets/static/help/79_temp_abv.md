## Поправка на давление
T кип = 100 + (P − 1013) × 0.028

Пример: P = 1000 гПа
T кип = 99.64°C (не 100°C)

## Применение
- Оценка крепости в кубе
- Прогноз остатка спирта
- Контроль процесса

## Точность
- ±5% при стабильном давлении
- ±15% при скачках

## Ограничения
- Только для воды/спирта
- Не для других смесей
- Учёт атмосферного давления
