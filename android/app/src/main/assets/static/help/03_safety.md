# Правила безопасности

## Обязательно
1. Никогда не оставляйте без присмотра
2. Обеспечьте вентиляцию
3. Не закрывайте выход пара
4. Контроль давления
5. Заземление оборудования
6. Огнетушитель рядом
7. Датчик разлития — обязательно

## Что делает система
- Стоп при T > 130°C
- Отключение ТЭН при отказе датчика
- Стоп при давлении > 3 бар
- Watchdog перезагружает задачи
- Anomaly detection

## Что система НЕ делает
- Не защитит от залипания реле
- Не защитит от засорения датчика
- Не защитит от ошибок оператора

## Аварийные ситуации
| Симптом | Действие |
|---------|----------|
| Скачок T > 100 | СТОП, снизить мощность |
| Пар из соединений | Проверить герметичность |
| Насос встал | АВАРИЙНЫЙ СТОП |
| Запах спирта | Проветрить, СТОП |
| Давление растёт | Аварийный сброс |
