# NTP

## Серверы
- pool.ntp.org
- time.google.com
- ru.pool.ntp.org

## Зачем
- Для ETA (время суток)
- Для меток в БД
- Для календаря

## Настройка
Настройки → NTP → Europe/Moscow

## Синхронизация
Автоматически при подключении Wi-Fi.
Раз в час — проверка.

## Формат времени
UTC внутренне.
Локально — с часовым поясом.

## Ошибки
- Не синхронизируется → Wi-Fi
- Сбивается → перезагрузка
- Разные зоны → смена TZ
