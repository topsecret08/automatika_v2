# MCP4725

## Характеристики
- 12-бит ЦАП
- I2C 0x60
- Выход: 0-VCC
- EEPROM для сохранения

## Подключение
- VCC → 3.3V или 5V
- GND → GND
- SDA → GPIO8
- SCL → GPIO9
- VOUT → LSA-TH3P40Y

## Команда
3 байта: [MSB][LSB][power_mode]
- power_mode: 0x60 (write + EEPROM)
- 0x40 (write + RAM)

## Расчёт
value = pct / 100 × 4095
buf[0] = value >> 8
buf[1] = value & 0xFF
buf[2] = 0x60

## Применение
- Управление мощностью ТЭН
- Аналоговые уставки
- Регуляторы

## Ошибки
- Питание от 3.3V → выход 0-3.3 В
- Для LSA нужно 0-5 В → питание 5V
- Без EEPROM сброс при перезагрузке
