# AI без интернета

## Работает без сети
- Предсказание экранов
- Предсказание действий
- Аномалии
- TinyML
- Обучение
- Экспорт на SD

## Нужен интернет
- Алиса
- Telegram
- BrewFather
- Календарь
- NTP

## Преимущества офлайн
- Нет задержек сети
- Приватность
- Работает в подвале
- Не зависит от провайдера

## Отключение Wi-Fi
Настройки → Флаги → Wi-Fi: OFF
AI-модули продолжат работать.
