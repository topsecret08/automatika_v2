# Датчик потока YF-S201

## Характеристики
- 1-30 л/мин
- Импульсный выход
- 450 импульсов на литр
- Напряжение: 3.3-5 В

## Подключение
- VCC → 3.3V
- GND → GND
- OUT → GPIO2 (счётчик импульсов)

## Применение
- Контроль охлаждения
- Стоп при 0 л/мин
- Подсчёт воды

## Расчёт
flow (л/мин) = pulses × 60 / 450 / time (сек)

## Монтаж
- Горизонтально
- Направление стрелки = поток
- Фильтр перед датчиком

## Аварийные пороги
- < 0.5 л/мин — предупреждение
- 0 л/мин — СТОП
- > 30 л/мин — ошибка

## Ошибки
- Не работает → нет потока или залип
- Пульсирует → воздух в системе
- Показывает 0 → фильтр засорён
