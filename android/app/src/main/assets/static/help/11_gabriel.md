# Метод Габриэля

## Суть
Двойная перегонка с делением браги на две части.

## Формулы
K = 0.30 + ABV/100 × 0.25
T1 = V × K
T2 = V − T1
Разбавить T1 до 28%
Выход = T1_alc × 0.85 / 0.65

## Порядок
1. Перегнать T1 → спирт-сырец
2. Разбавить T1 до 28%
3. Перегнать → сердце (2-я)
4. T2 — на следующий раз

## Пример
V=20 л, ABV=10%
K = 0.30 + 0.025 = 0.325
T1 = 6.5 л, T2 = 13.5 л
Спирт T1 = 0.65 л
Разбавить до 28% → 2.32 л
Выход 65% ≈ 0.85 л

## Плюсы
- Экономия энергии
- Концентрация ароматов

## Минусы
- Требует точности
- Больше итераций

## Ошибки
- Нельзя смешивать T1 и T2
- Разбавление обязательно
- Не отбирать головы на 1-й
