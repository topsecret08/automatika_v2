# PCA9685

## Характеристики
- 16 каналов PWM
- 12-бит разрешение
- I2C 0x40
- Частота: 24-1526 Гц

## Подключение
- VCC → 3.3V (логика)
- V+ → 5V (сервы, отдельно!)
- GND → GND (общий с V+)
- SDA → GPIO8
- SCL → GPIO9

## Управление сервой
Период 20 мс (50 Гц)
- 1 мс → 0°
- 1.5 мс → 90°
- 2 мс → 180°

## Регистры
- MODE1 0x00 (sleep/wake)
- PRESCALE 0xFE (частота)
- LED0_ON_L 0x06 (первый канал)

## Настройка
1. Sleep (MODE1=0x10)
2. PRESCALE = 121 (50 Гц)
3. Wake (MODE1=0x20)
4. Задержка 5 мс

## Ошибки
- Питание V+ от ESP32 → просадка
- Общий GND отсутствует → не работает
- Частота > 100 Гц → сервы жужжат
