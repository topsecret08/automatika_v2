# Экспорт AI-моделей

## Что экспортируется
- 4 нейросети
- Markov-таблица
- Статистика точности

## Куда
/sdcard/ai/export_YYYYMMDD.bin

## Формат
- Заголовок: версия, размер
- Данные: веса int8
- CRC32 в конце

## Применение
- Резервная копия
- Перенос на другое устройство
- Обмен с друзьями

## Импорт
AI → Импорт моделей.
Проверка версии → замена.

## Совместимость
- Разные версии — предупреждение
- Другое оборудование — может быть неточность
- Идеально — копия вашей модели
