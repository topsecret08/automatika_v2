# Сброс калибровки DS18B20

## Что делает
Сбрасывает индивидуальные поправки к 0.
Датчики к заводским значениям.

## Когда нужно
- После перепайки
- При замене датчика
- Если поправка стала некорректной
- После ошибки в калибровке

## Что НЕ сбрасывается
- Настройки датчиков
- Адресация
- Роли (какой за что)

## Как сбросить
Настройки → Калибровка → Сбросить всё.
Требуется PIN инженера.

## После сброса
Паспортная точность ±0.5°C при −10…+85°C.
Рекомендуется перекалибровать.
