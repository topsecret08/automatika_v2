# Датчик вакуума

## Характеристики
- Диапазон: 0-1000 мбар
- Выход: 0.5-4.5 В
- Питание: 5 В
- Тип: пьезорезистивный или ёмкостный

## Подключение
- VCC → 5 В
- GND → GND
- OUT → ADS1115 A1

## Формула
mbar = (V - 0.5) / 4.0 × 1000

## Пример
V = 1.5 В → mbar = 250
V = 4.5 В → mbar = 1000

## Калибровка
1. Открытый воздух → 0 мбар
2. Отключить насос
3. Если не 0 — корректировать offset

## Применение
- Вакуумная дистилляция
- Контроль герметичности
- Управление насосом

## Тест утечки
1. Закрыть клапаны
2. Насос на 1 мин
3. Отключить
4. Замерять рост давления
5. Рост > 5 мбар/мин — утечка

## Ошибки
- Показывает 0 всегда → нет питания
- Скачет → плохой контакт
- Не растёт → вакуум не создаётся
