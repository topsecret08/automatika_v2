# Охлаждение сусла

## Когда
После кипячения — быстро до 20-25°C.

## Режимы
- Автоматический — открыть клапан
- Ручной — управление насосом

## Методы
- Погружной чиллер
- Противоточный чиллер
- Пластинчатый чиллер

## Скорость
- 20 л за 15-30 мин (чиллер)
- 20 л за 5-10 мин (пластинчатый)

## Контроль
- Мониторинг T куба
- Автостоп при достижении цели
- Автоподача воды

## Важно
- Не охлаждать слишком быстро (инфекция)
- Следить за потоком воды
- Закрывать крышку после охлаждения

## Ошибки
- Резкое охлаждение → «cold break» белков
- Слабое охлаждение → ожог дрожжей
- Открытая крышка → инфекция
