# QR-коды

## Wi-Fi QR
Формат: WIFI:S:SSID;T:WPA;P:pass;;
Сканировать камерой телефона.

## URL веб-интерфейса
http://192.168.x.x/
Открывается в браузере телефона.

## API-токен
Для интеграций и HA.

## FOTA через QR
URL прошивки → скачивание.

## Где найти
Меню → QR-коды.

## Применение
- Быстрая настройка
- Обмен с друзьями
- Массовое развёртывание

## Ошибки
- Не сканируется → уменьшить яркость
- Не подключается → проверить пароль
