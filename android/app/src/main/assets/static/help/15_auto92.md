# Формула Авто-92+

## Формула
V = Vmax × (6.04 − 0.06 × T)

## Значения
| T, °C | Множитель |
|-------|-----------|
| 85 | 0.94 |
| 88 | 0.76 |
| 90 | 0.64 |
| 92 | 0.52 |
| 94 | 0.40 |
| 95 | 0.34 |
| 98 | 0.16 |

## Включение
Настройки → Флаги → Авто-92+

## Автообучение
Коэффициент 0.06 корректируется AI.

## Зачем
Без Авто-92+ отбор остаётся высоким до 92°C —
это даёт скачок T и «прорыв» хвостов.

С Авто-92+ отбор плавно снижается,
обеспечивая стабильность.
