# Баланс спирта

## Формула
Спирт = Объём × Крепость / 100

## Пример
20 л × 12% = 2.4 л чистого спирта.

## Расчёт остатка
По текущей T кипения:
- 78.3°C → 96%
- 85°C → 65%
- 90°C → 43%
- 100°C → 0%

## Зачем
- Понять, когда заканчивать
- Оценить эффективность
- Прогноз выхода

## Экран
Мониторинг → Баланс спирта.
Ввести объём и крепость браги.
Система считает в реальном времени.

## Точность
±5% при стабильном давлении.

## Применение
- Дистилляция
- Ректификация
- НБК
