# ПВК (Пароводяной котёл)

## Что это
Рубашка вокруг куба: вода → пар. Для густых браг.

## Режимы
- ВОДА — до 100°C
- ПАР — 100-130°C
- АВТО — переключение по T

## Безопасность
- Датчик давления ОБЯЗАТЕЛЕН
- Автодолив в рубашку
- Стоп при P > 3 бар
- Стоп при T > 130°C

## Пресеты
- Затирание зерна (65°C, ВОДА)
- Варка пива (100°C, АВТО)
- Густая дистилляция (110°C, ПАР)
- Ректификация (118°C, ПАР)
- Стерилизация (120°C, ПАР)

## Применение
- Густые браги
- Пивоварение
- Стерилизация
- Варка варенья
- Томление
