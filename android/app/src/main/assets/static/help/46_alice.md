# Яндекс.Алиса

## Что умеет
- «Алекса, старт процесса»
- «Алекса, стоп»
- «Какая температура в кубе?»

## Настройка
1. Настройки → Алиса
2. OAuth-токен
3. Device ID

## Требования
- HTTPS-сервер
- Публичный IP или туннель
- Регистрация в Яндекс.Диалоги

## Endpoint
POST /alice
{
  "request": {"command": "старт"},
  ...
}

## Ответ
{
  "version": "1.0",
  "response": {
    "text": "Запускаю процесс",
    "end_session": false
  }
}

## Ограничения
- Работает только через облако
- Задержка 1-2 сек
- Не подходит для критичных операций

## Ошибки
- Не слышит → микрофон
- Не отвечает → endpoint
- Токен истёк → обновить
