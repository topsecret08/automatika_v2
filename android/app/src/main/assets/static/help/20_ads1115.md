# ADS1115

## Характеристики
- 4 канала single-ended
- 16 бит разрешение
- I2C 0x48 (ADDR→GND)
- PGA: ±6.144 В
- Скорость: 8-860 SPS

## Подключение
- VCC → 3.3V
- GND → GND
- SDA → GPIO8
- SCL → GPIO9
- ADDR → GND (0x48)

## Применение
- A0: датчик давления (4-20 мА + 150 Ω)
- A1: датчик вакуума (0.5-4.5 В)
- A2: датчик разлития
- A3: MQ-3 (пары спирта)

## Формулы
Давление (4-20 мА):
mA = (V/150)×1000
bar = (mA-4)/16×4

Вакуум:
mbar = (V-0.5)/4×1000

## Ошибки
- Не подключён ADDR — адрес плавает
- Плохой контакт — шум
- Нет подтяжки I2C — не работает
