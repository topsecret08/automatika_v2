# Backup БД

## Backup
Копия в /sdcard/backups/db_YYYYMMDD_HHMM.db

## Зачем
- Перед экспериментами
- Перед сменой оборудования
- Раз в месяц

## Восстановление
1. Скопировать backup
2. Переименовать в automatika.db
3. Перезагрузить

## Автобэкап
Каждый день в 03:00.
Хранится 7 копий.

## Размер
~5-10% от основного файла (сжатый).

## Облако
Можно копировать на Google Drive.

## Ошибки
- Файл повреждён → старее копию
- Не влезает → очистить
