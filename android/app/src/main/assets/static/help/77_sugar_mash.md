# Сахарная брага

## Формула
На 20 л:
- Сахар: 4-5 кг (20-25%)
- Дрожжи: 100 г (сухие)
- Вода: до 20 л

## Выход
~2.4 л спирта (96%).

## Приготовление
1. Растворить сахар в тёплой воде
2. Охладить до 25-30°C
3. Внести дрожжи
4. Гидрозатвор
5. Брожение 7-14 дней

## Контроль
- Начальная плотность: 1.080-1.100
- Конечная: 1.000-1.010
- Температура: 20-28°C

## Turbo-дрожжи
За 3 дня, но больше сивушных.

## Инвертирование
Сахар + лимонная кислота (2 г/кг) + вода.
Нагрев 80°C 30 мин. Быстрее бродит.

## Ошибки
- Много сахара → не дображивает
- Мало дрожжей → медленно
- Высокая T → гибель дрожжей
- Без гидрозатвора → уксус
