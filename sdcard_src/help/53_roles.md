# Роли и доступ

## Роли
- **Гость** — только просмотр
- **Оператор** (PIN 1111) — запуск/стоп
- **Инженер** (PIN 2222) — настройки
- **Админ** (PIN 3333) — прошивка, сброс

## Автовыход
5 / 10 / 30 минут или никогда.

## Отключение ролей
Настройки → Роли → Система ролей: OFF
Все операции доступны без PIN.

## PIN по умолчанию
- Оператор: 1111
- Инженер: 2222
- Админ: 3333
- Мастер: 9999

## Изменение
Настройки → Роли → Изменить PIN.
Требуется текущий админ.

## Забыли PIN
Полный сброс через перемычку на GPIO0
при старте → сброс NVS.
