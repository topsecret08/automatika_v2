# FAQ

**Q: Какое железо нужно?**
ESP32-S3-N16R8 + ST7796 + датчики.

**Q: Без интернета работает?**
Да, полностью.

**Q: Можно без SD?**
Ограниченно — без справки и рецептов.

**Q: Насколько точно?**
DS18B20 ±0.5°C (после калибровки ±0.05°C).
PT100 ±0.1°C.

**Q: Обновлять обязательно?**
Нет, но рекомендуется.

**Q: Промышленное применение?**
Да, ПВК и НБК.

**Q: Гарантия?**
Нет, Open Source.

**Q: Сколько стоит?**
Компоненты ~15-25 тыс. руб.

**Q: Сложно собрать?**
Средне. Нужен паяльник и базовые навыки.

**Q: Поддерживает 220V?**
Да, через LSA-TH3P40Y.

**Q: Много ли ошибок?**
Стабильно после первых процессов.

**Q: Помощь?**
GitHub Issues, Wiki.

**Q: Можно продавать?**
Только по закону. Проверьте лицензии.
