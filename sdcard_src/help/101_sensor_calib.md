# Калибровка DS18B20 «Горячая ванна»

## Зачем
Заводская точность ±0.5°C.
После калибровки можно достичь ±0.05°C.

## Принцип
Все датчики окунаются в одну жидкость.
Среднее по всем — эталон.
Отклонение каждого = его поправка.

## Использование разрешения
DS18B20: 0.0625°C.
Наша система применяет:
- Медианный фильтр 9
- Усреднение 16 значений
- Индивидуальная поправка

Итог: ±0.05°C.

## Пошагово
1. Подготовка воды 40-80°C
2. Окунуть все датчики
3. Перемешать
4. Настройки → Калибровка → Старт
5. Дождаться стабилизации
6. Применить и сохранить

## Ручной эталон
Если есть проверенный термометр —
ввести его показание.

## Ошибки
- Плохой контакт → СКО высокое
- Не перемешано → разные T
- Не все датчики → некорректно
