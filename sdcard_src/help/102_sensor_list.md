# Список датчиков DS18B20

## Что показывает
- Номер датчика
- 64-битный ROM-код
- Текущая T
- Поправка
- СКО шума
- Индикатор калибровки

## СКО шума
- < 0.01°C — отлично
- 0.01-0.05°C — хорошо
- 0.05-0.1°C — терпимо
- > 0.1°C — плохой контакт

## Диагностика
Если СКО высокое:
- Проверить подтяжку (4.7 кΩ)
- Укоротить кабель
- Экранированный провод
- Конденсатор 0.1 мкФ

## Применение
- Проверка перед процессом
- Поиск неисправных
- Планирование замены

## Меню
Настройки → Калибровка → Список датчиков.
