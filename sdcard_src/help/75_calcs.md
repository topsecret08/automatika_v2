# Калькуляторы

## 8 калькуляторов
1. Разбавление спирта
2. Сахарная брага
3. Зерновая брага
4. Выход продукта
5. ABV / IBU / SRM
6. Крепость по T
7. Коррекция давления
8. Метод Габриэля

## Формат
JSON в /sdcard/calc/.
Можно добавлять свои.

## Использование
Меню → Калькуляторы → выбрать.
Слайдеры ввод → результат сразу.

## Экспорт
Результат можно скопировать в рецепт.

## Ошибки
- Не загружается → JSON битый
- Неверный расчёт → формула
