# FT6336U — тачскрин

## Характеристики
- Ёмкостный
- I2C 0x38
- Прерывания GPIO39
- Мультитач до 2 точек

## Подключение
- VCC → 3.3V
- GND → GND
- SDA → GPIO8
- SCL → GPIO9
- INT → GPIO39
- RST → GPIO38

## Использование
LVGL indev через esp_lcd_touch_ft5x06.

## Регистры
- TD_STATUS 0x02 (число касаний)
- TOUCH1_XH 0x03 (координаты)

## Калибровка
- Обычно не требуется
- Если смещение — проверить RST
- Инверсия по X или Y — swap_xy

## Ошибки
- Не реагирует → INT не подключён
- Двойные нажатия → плохой контакт
- Смещение → калибровка в LVGL
