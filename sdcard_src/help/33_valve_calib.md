# Калибровка клапанов

## Зачем
Знать реальный объём отбора (мл/ч).

## Горячая калибровка
Работает в фоне, не прерывая процесс.

## Шаги
1. Клапаны → Калибровка → выбрать
2. Указать ожидаемый объём (100 мл)
3. Собрать продукт в мерный цилиндр
4. Ввести фактический объём
5. Система рассчитает мл/ч

## С весами
Автоматически через HX711:
- Запустить процесс
- Установить мерную ёмкость на весы
- Система считает мл через вес

## Формула
ml_per_hour = actual_ml × 3600000 / total_open_ms
ml_per_open = actual_ml / open_count

## Точность
- Вручную: ±5%
- С весами: ±1%

## Периодичность
- После замены клапана
- При смене вязкости продукта
- Раз в 10-20 процессов

## Ошибки
- Слишком короткое окно → неточность
- Слишком длинное → потеря продукта
- Пузыри в жидкости → завышение
